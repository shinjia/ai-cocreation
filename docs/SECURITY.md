# 安全、資料與能力邊界

## 僅本機

本包沒有使用者帳號、團隊管理、多人權限、公開服務用量／費用配額、公開網站防濫用或第三方登入。只接受設定為 localhost/127.0.0.1/[::1] 的網址與真正 loopback 來源，拒絕 Forwarded、X-Forwarded-*、X-Real-IP 等代理標記。Host、Origin、同站來源與 CSRF 均驗證；不提供 CORS。請勿透過隧道、反向代理或區網公開它。

所有讀寫以隨機瀏覽器 owner 限定；這不是完整帳號安全機制。共用電腦的同一瀏覽器代表同一工作者。Cookie/session 遺失沒有帳號復原途徑。

## 金鑰

- 只有專用密碼欄接受既有 OpenAI Key。前端送出前清空欄位，不把 Key 存到 localStorage、sessionStorage、IndexedDB、DOM屬性、狀態物件或作品匯出。
- Key 暫存在網站根目錄外的私有檔案，POSIX 權限目錄0700／檔案0600。Windows 需管理者將 ACL 限定 Apache/PHP 帳號，本程式不能證明系統ACL安全。
- 可用期限30分鐘，每次讀取檢查期限。實體過期檔案在後續請求時才清除，**沒有背景計時刪除，若不再開啟程式，檔案可能仍存在**。用完請主動按清除。
- Key 不寫入 SQLite、設定檔、請求紀錄、錯誤訊息或JSON匯出。請求紀錄只保存必要識別、狀態、雜湊和結果專案／版本識別碼，不保存完整生成提示或圖片。
- 私有資料夾備份可能包含仍暫存的 Key／Session，須離線、私密保管，不要分享整個私有目錄。若不需保留工作階段，可先自行清除 Key 再備份；同系列更新本身不要求清除或重填 Key，也不延長其期限。
- AI 成員清單與一次性使用同意只保存非秘密設定，不含 Key；本次工作階段的 OpenAI 成員共用同一份暫存 Key。這份同意不是長期保存金鑰的授權，也不延長 30 分鐘期限。

## AI 連線與費用

OpenAI 目的地固定為官方 HTTPS；驗證憑證、不跟隨重新導向、不使用環境代理。模型清單查詢與連線檢查只讀取模型資訊；對談與結構化作品使用 Responses API、strict JSON Schema、store:false；圖片專用路徑另用 Images generations／edits JSON API，不沿用或聲稱有 Responses 的 store:false 參數。store:false 不是對 OpenAI 所有服務日誌／保留政策的零保留承諾。

Ollama 只允許同機 HTTP loopback、埠號1024至65535；不允許帳密、任意路徑、查詢、片段或非本機主機。localhost 解析被固定到127.0.0.1，關閉重新導向與代理。只能呼叫固定 `/api/chat` 與 `/api/tags`，不會傳送 OpenAI Key。使用者仍需確保該埠是可信的 Ollama 服務；這不是對另一個本機程式的信任認證。Ollama 自行設定的雲端／轉送服務不在此原型保證範圍。

初次設定需明確勾選並保存資料傳送與費用說明。之後由使用者明確按送出、整理目標、生成、比較或明確融合，直接使用專案初次選定的已啟用成員，不逐次彈窗。這份應用使用同意與創作目標確認分開；沒有同意、沒有啟用成員或尚未選人時阻擋推論。舊設定遷移為「原有設定」成員，使用同意預設為 false，不承襲過去單次請求的同意。新增啟用成員或更換服務、網址、模型時，設定介面要求重新核對並勾選；不是對任意未來目的地的同意。

專案對談與圖片各自一次選定後，分別固定 memberId、稱呼、供應者、模型與目的地；圖片綁定不改既有對談／Ollama 設定。舊專案沒有綁定時需明確選定一次，不從中央目前選人偷偷推定。中央移除、停用或改變同一成員的服務／模型／位置會阻擋原專案，不暗中換人。每次請求仍綁定成員 ID、供應者、模型、設定代次及 OpenAI Key 代次，避免在途中設定改變後送到錯誤服務。選擇成員、保存設定、開啟頁面不自動推論，不同時或輪流呼叫多個成員，不自動降級或轉換服務。未知結果、逾時與格式錯誤不自動重試；先查看最新狀態，再決定是否明確建立新請求。

讀取可用模型只由使用者明確按鈕觸發，不自動查詢、下載或推論。清單是服務當次回報的中繼資訊，不保證模型支援所需結構化輸出；手動輸入與最近使用紀錄更不是可用性保證。失敗會顯示原因，不以虛構清單代替。

文字／原生作品的 AI 生成或修訂時，本版目標與修改整理由同一次模型回覆取得；圖片操作由使用者指示及已保存方向／來源目標直接組合提示，兩者都沒有額外摘要或提示撰寫呼叫。傳送內容可包含該項目的完整討論、專案脈絡、固定引用及此次操作所需的版本文字與完整表格／圖表／心智圖／向量圖形／網頁／圖文／海報／互動視覺原生來源；選 OpenAI 即傳送至 OpenAI，選 Ollama 則送到已設定的同機服務。請在操作前確認內容適合交給該服務。

## 內容與來源

- 所有使用者／模型文字用安全文字DOM渲染，不執行HTML、程式或腳本。
- 標題內容 1 至 12 欄，每欄最多 6,000 UTF-8 bytes，合計最多 24,000 bytes；短文為一份完整全文，最多 12,000 bytes。長篇文章 1 至 80 段，每段最多 6,000 bytes、完整保存最多 120,000 bytes；AI 單次生成／融合最多 36,000 bytes，修訂前選段原文最多 24,000 bytes。長文 AI 只回傳明確選段，再由伺服器合併未選原文成完整新版本。「本版目標與修改意見」合併欄位最多 12,000 bytes，比較問題最多 2,000 bytes。舊相容欄位與模型輸出仍保留各自長度驗證；前端提示與後端驗證並行，不把字數當成位元組數。
- 原始 JSON 請求上限為 1 MiB（1,048,576 bytes），容納完整版本及中繼欄位，但不放寬逐欄限制。標題模型脈絡上限為 240,000 bytes，短文／文章／表格／圖表／心智圖／向量圖形／網頁／圖片／圖文／海報／互動視覺為 600,000 bytes；超限停止，不默默截斷歷史。
- 單專案 30 個創作項目，每項 60 版本（含封存）與 60 比較；每個專案序列化內容最多 2,000,000 bytes，並非整個 SQLite 資料庫的總容量上限。
- 比較只接受目前創作項目的 2 至 5 個不同且未封存版本，依各版自己的目標、變更與意見評估，不以目前共用目標排名。回覆必須逐一匹配所選 ID，不接受 AI 憑空替換版本；缺少歷史記錄不事後捏造。
- 正式版只是明確選定的指標；主版本、小版本、AI 候選及手動保存都追加完整快照，不覆寫原內容、ID 或來源。候選封存只改項目層的封存 ID 清單；正式版不能封存，還原不刪改歷史。定稿與專案結案各有獨立明確操作。
- AI 成員有穩定 ID。新回覆、版本及比較固定當時成員稱呼、供應者、要求／實際模型；停用或改名不重標歷史，舊資料缺欄位不以現設定補造。
- 明確融合保存所選版本的完整直接內容、目標與來源；內嵌來源的更早融合只保留版本 ID 關係，不遞迴複製祖先樹。融合不代表採用或定稿。
- 跨創作項目引用固定完整版本，來源改動不會更新引用。生成版本也保存當時引用快照、共享脈絡及模型來源，便於追溯。
- 專案名稱／說明、項目名稱／說明或引用變動後，新一批生成與定稿需重新整理及確認目標；既有正式版可在保留失效標記的情況下繼續修訂。比較使用各版本已保存的目標，不要求目前目標已確認，也不假造目標同意。已定稿項目需先重新開啟才能改動。

## 表格／圖表安全與匯出界線

- 表格以真正的 columns／rows／cells 儲存，所有格子是文字，不執行公式、HTML 或腳本。原生作品只接受指定欄位，列欄 ID 唯一、每列格數一致；前後端各驗證，伺服器以 artifact 重新產生文字投影，不信任客戶端另傳的內容摘要。
- 流程圖使用受限 Mermaid 風格語法與自製 SVG，不載入 Mermaid／CDN 或執行來源文字。只接受明確節點、箭頭、純文字標籤及支援的方向，拒絕初始化指令、子圖、class／style、click、HTML、Markdown、圖片、網址及任意程式。來源經解析後才用固定 SVG 元素／屬性生成預覽；文字用 textContent，匯出進行 XML 跳脫，不加入外部資源或連結。
- 流程圖最多 40 節點、80 連線；允許循環／自我連線，但排版不作無界走訪。這是有限簡化圖形能力，不是任意 Mermaid 的安全沙箱，也不保證完整 Mermaid 或圖坊相容。完整節點與連線另以文字列表顯示，圖面縮略不改來源。
- 統計圖只接受有界 TSV，1–5 數列、1–24 列資料，數值為有限十進位、絕對值不超過 1 兆；公式與非數字拒收。不得為湊圖捏造未提供的數據，也不得把固定示範資料當作使用者的事實。
- 表格最多 12 欄、100 列，每格 2,000 bytes；圖表來源最多 12,000 bytes；兩者完整 artifact JSON 及文字投影各最多 60,000 bytes。超限或不合法輸出拒收，不略過有問題的部分假裝成功。大容量仍受專案總量與模型輸出預算限制。
- 生成、候選微調、手動保存及融合都追加完整 typed artifact，不覆寫來源；固定引用與定稿包含完整原件。只有明確採用才變更正式版，來源不會因外部資料或後續版本自動同步。
- CSV／TSV 匯出為以 `=`、`+`、`-`、`@`、Tab／CR／LF 起頭的文字，以及以一般空白後接公式符號的文字，加前置單引號降低試算表公式注入風險。已驗證的統計數值欄保留數字，包括負數；這不保證所有第三方試算表匯入設定都安全。原始文字仍在 JSON，分享與匯入前應自行檢查。
- 匯出與剪貼簿只能由明確按鈕觸發，操作已保存版本；不呼叫 AI、不上傳或同步到外部工具。CSV／TSV、MMD 與 SVG 不含完整版本／來源關係，不能當成專案備份；專案 JSON 可能包含私人文字、流程與統計，分享前需檢查。

## 向量圖形安全與保存邊界

- 向量是嚴格原生資料，不接受任意 SVG／XML、HTML、CSS、JavaScript、path、貝茲曲線、圖片、外部 URL、字型、濾鏡或漸層。預覽／匯出只建立已知 SVG 元素與固定屬性；文字使用安全 DOM 與 XML 跳脫，不執行文字中的標記。
- 原始 JSON schema 在轉換前核對真正物件／陣列、有限數字、整數與上下限，不把數字字串、布林值或 null 當數值。語意層另驗證全部精確欄位、全圖唯一穩定 ID、幾何類型及其跨欄位要求。六位十六進位色碼／none 以外的填色或外框拒收，不能透過 url() 載入資源。
- 1–100 個物件，畫布寬高各為 1–4096 整數；座標／局部頂點 -4096 至 8192，物件寬高／線段位移 -8192 至 8192，矩形／橢圓寬高須正值。外框寬度 0–100、不透明度 0–1、文字大小 1–512，數值最多三位小數。超精度或超限拒收，不默默四捨五入或截斷；多邊形 3–80、折線 2–80 個頂點，其餘類型不得夾帶頂點。
- 標題最多 600、物件名稱 120、文字內容 4,000 UTF-8 bytes；完整原生 artifact JSON 與緊湊投影各最多 60,000 bytes。伺服器仍核對最終序列化位元組數，PHP 非預設 serialize_precision 可能使其更嚴，不把前端通過當成保存保證。投影由 artifact 重新生成，不信任客戶端另送文字。
- 欄位輸入、已套用草稿及已保存版本分開。尚未套用欄位在同頁重畫、物件切換及狀態讀取時保留，但不寫 localStorage／sessionStorage，也不是持久保存。整頁重新整理或關閉會失去未另存內容；20 步復原僅屬目前頁面草稿。未套用內容須先套用或明確放棄，才可進行會丟字的操作及外層另存。
- 修訂、融合、手動主／小版、比較來源、固定引用、正式版及定稿保存完整原生作品與來源；只有明確採用改正式版。AI 使用已保存來源，不讀頁面草稿；釐清須回傳相同作品後捨棄。融合拒絕與任一來源相同的繪製資料，名稱、ID 或等值色碼大小寫改動不能冒充新融合；圖層順序與重複物件仍有意義。
- SVG 匯出保留獨立原生幾何與文字，不內嵌點陣圖。通用字型由本機軟體決定，不保證其他工具字型或排版相同；超出畫布的物件只在顯示時裁切，原生資料仍保留。JSON／TXT 保存完整原生資料，均可能包含私人文字，分享前需檢查。單件匯出不含完整版本歷史，不能取代專案 JSON 備份。
- 匯出只由明確按鈕處理已保存版本，不呼叫 AI、不上傳或同步至外部工具。使用者所稱「形坊」的目前名稱與匯入規格尚未核對，不保證匯入相容性，沒有外部連接器或雙向同步。

## 網頁安全、固定圖片與匯出邊界

- 原件是嚴格原生資料，只接受固定 root／區塊／條目欄位，theme 為 paper／midnight／meadow，區塊為 hero／text／cards／faq／cta／image。不接收 HTML、CSS、JavaScript、事件、任意屬性、外部圖片 URL、內嵌位元組、作者 data URL 或檔案路徑；標記、網址與換行原樣作純文字，不轉為外部連結。
- 三部分方向仍為視覺風格、內容結構、操作功能與限制，精確有序確認清單與最新 summaryRevision 在伺服器核對；勾選不推論／保存，明確 confirm_generate 才生成。相容 approve_goal 同樣驗證，圖片選用不取代方向確認。
- 前後端驗證真正物件／密集陣列／boolean、精確欄位與穩定 ID。1–20 區塊，cards／faq 每區 1–12 條目，image 恰 1 條，entry.id 必須是 32 個小寫十六進位固定圖片 pin；title 為非空替代文字（600 bytes）、body 為可空圖說（6,000 bytes）。其餘文字限制及完整正規 JSON／投影 60,000-byte 上限保留，超限不截短。
- hero 可有、cta 必須有頁內按鈕，其他類型（含 image）禁止 action；文字與目標成對，target 僅為同頁既存區塊 ID，不能是 URL、DOM selector、`#` 片段或別項目。預覽以各作品獨立 DOM ID 隔離，FAQ 使用原生 details／summary。
- 圖片來源只限同專案明確直接釘選的圖片版本，或明確釘選的 illustrated／poster 固定版本實際使用的圖片。後端重新核對該確切保存版本、型別與 artifact，不讀最新正式版、不展開未用引用、不搜取未釘選項目。衍生圖片 pin 保留完整快照與 viaReferences 來源；metadata／合法 ID 本身不是授權。
- 推論／保存前驗證 owner、project、item、version、snapshot.id、完整 image artifact、私人 BLOB descriptor／長度／SHA-256。跨範圍、缺漏、變造、同 ID 不同快照一律拒絕，不默選一張或改取新版。availableImageReferences 是 view 的衍生選單，不入持久資料；view 可只核對快照，但不取代操作時資產重驗。
- 新網頁版本保存目前明確引用與實際使用的完整歷史／衍生圖片 pin。移除目前引用不改舊版；預覽與匯出只用自身 referencesSnapshot，不能借當前選單補缺圖。AI 修訂／手動主小版／比較／融合／採用／定稿維持完整不可覆寫歷史，參照來源改版不自動連動。
- 固定文字模型只收 allowlist 中繼資料：圖片標題、替代文字、來源註記、尺寸／MIME、固定來源識別，明示 pixelsProvided=false／imagePixelsProvided=false。不傳 asset descriptor、PNG、base64、data URL、讀圖路徑或 transport 圖片附件。圖片分析同意不會放寬網頁路徑；本機預覽與匯出讀圖不是 AI 看圖，不新增圖片服務或像素生成。明顯看圖／生圖假宣稱有有界說明檢查，但不是全語言語意真實性保證。
- 手動新增圖片區必須明確選圖，不預選第一張；替代文字與圖說只改網頁、不改圖片來源。未套用欄位跨同頁切換／busy 重畫保留，先套用或放棄再另存及破壞性操作，20 步復原只改草稿；整頁重整／關閉不保留。AI 不讀未另存內容，過期回呼不能作用於新來源。
- 預覽用固定 DOM／scoped CSS 與 textContent，不用 innerHTML 或 iframe 執行作者來源。私人圖片沿同源 POST／CSRF／owner 的既有讀取流程建立短暫 Blob URL，重畫／dispose 清理。僅頂端正式版自動讀圖，其餘候選／歷史／引用／比較與草稿須明確載入，不開頁就讀全部歷史。主工作室 CSP、本機與 Key 邊界不變。
- 含圖 HTML 必須非同步取得該保存版確切 PNG。共用 private-image-export helper 不自行 fetch 或決定權限；呼叫端提供已授權 reader。每張最多 4 MiB，按每個圖片區出現累加最多 20 MiB raw PNG；同圖可去重讀取，容量不得去重。重驗 Blob MIME／實際長度、PNG 簽章／完整有界區塊／CRC／尺寸及 SHA-256，不能用同尺寸另一圖替代。
- 每個 await 的成功／失敗前後都檢查目前操作，含私人讀取、arrayBuffer 與 hash。缺漏／衝突引用、錯格式／hash、讀取失敗、取消或 stale 一律整筆停止，不產生部分缺圖成品、不自動重試。全部成功後才建立下載，DOM／Blob／crypto 測試替身不是真實瀏覽器驗收。
- HTML 僅輸出固定 CSS、安全跳脫文字及程式產生的 PNG data URL。charset 後即放 CSP；含圖版 img-src 僅 data:，style-src 僅固定內嵌樣式的 unsafe-inline，其餘 script／connect／font／frame／object／media／worker／base／form 禁用。無外部資源、JavaScript 或表單，不改工作室 CSP；純文字網頁仍沿用 img-src none 的既有 HTML 流程。
- 含圖 JSON `{notice,artifact}` 與 TXT 警語／原生 JSON 只含文字、結構和引用 ID，不含 PNG 或完整來源快照，不是圖片備份。無圖 JSON／TXT 的原有格式保留；專案 JSON 有完整歷史但同樣不含 PNG。含圖 HTML 真的包含私人圖片、替代文字及來源註記，分享前須核對隱私及圖片使用權；沒有匯入／自動還原、部署、登入、付款、表單或 API 服務。

## 外部圖片、實際像素分析與私人媒體

### 選檔不等於上傳，上傳不等於模型分析

- 正式頁只接受使用者明確選擇的靜態 PNG／JPEG；瀏覽器先按真實位元組檢查，不信任檔名／MIME，不接收圖片 URL、伺服器路徑、SVG、GIF、WebP 或 APNG。原始檔上限 12 MiB、每邊 8192、總像素 16,777,216；有界標頭檢查之後仍須真正解碼。
- 依來源方向及明確選擇的 0／90／180／270 度旋轉，不放大，產生最長邊 2048、上限 4 MiB、保留透明度的 PNG 副本。準備、旋轉、預覽及取消不呼叫 AI、不上傳；只有明確保存才傳至此安裝站。檔名不自動當作標題或外部傳送名稱，原檔保持不變。
- 伺服器只接受 8-bit RGB／RGBA 非交錯 PNG，重驗全部有界區塊、CRC、標準 zlib、精確解壓列長及濾鏡，再重新壓縮成 IHDR／單一 IDAT／IEND。拒絕 APNG、tRNS、調色盤及其他不支援格式，不能只修改副檔名繞過。這不依賴 GD，需 PHP zlib。
- 輸出不保存原檔名、EXIF／IPTC／XMP、色彩描述檔或其他 ancillary 資料。瀏覽器解碼／縮圖及 profiles 移除可能改變顯示色彩，不保證原始像素、印刷色彩或典藏忠實度。來源註記由使用者提供，程式不自動驗證著作權、授權或真偽。
- PHP 解壓及模型編碼前均以目前記憶體用量和限制保守預留多份副本；不足或無法安全確認就拒絕，不放寬 memory_limit。名義 4 MiB／2048 或每次分析 12 MiB 不是每台主機都能接受的保證，請縮小圖片或減少張數。

### 私有讀取與歷史完整性

- 正規 PNG 以私有 SQLite BLOB 保存，並無公開檔案路徑／資產 URL。MediaStore 只以同一既有 PDO 增建 media_assets／media_upload_receipts 兩表，不替換設定或資料庫、不清除資料。上傳的資產、完整版本和 receipt 在一筆 BEGIN IMMEDIATE 交易內保存，出錯一起回滾；不留下只有版本沒有資產的半筆成功。
- 上傳和 read_image 都走同 Origin、Session／owner、CSRF 的 POST；GET 不提供圖片。讀取必須解析確切 owner／project／item／saved version，核對資產 owner、項目、完整 descriptor、長度及 SHA-256。僅持有 asset ID 或自行編造 metadata 不能取得內容，不能指定外部 URL 或檔案路徑。
- 專案 JSON 請求仍上限 1 MiB。圖片 multipart 限 4 MiB PNG，加最多 32 KiB metadata payload，整個端點上限 4,325,376 bytes；read_image 的 JSON 上限 64 KiB。PHP upload_max_filesize 至少 4M、post_max_size 至少 5M，不需提高主 JSON API 上限。
- 只有頂端正式版自動讀圖，其餘版本／引用／比較需明確載入，避免自動下載全部歷史 BLOB。私有回應維持 no-store、nosniff 及 Cross-Origin-Resource-Policy: same-origin。預覽用 POST 取得 Blob，再建立本機 object URL，重畫／關閉／錯誤即 revoke。主頁 CSP 只在原有 img-src self／data: 上加入 blob: 供私人預覽，其餘指令不放寬；應用仍不接受作者指定圖片 URL／data URL，也未新增腳本或 iframe 執行來源，不宣稱為任意程式沙箱。
- 每專案最多 100 資產／64 MiB，每 owner 最多 400 資產／256 MiB。封存／定稿／固定引用保留原資產，沒有垃圾回收，不藉封存刪除或釋放額度。手動 metadata snapshot 必須沿用所選版本的同一 asset；僅改標題、替代文字、來源註記與本版目標，不能偷換像素或跨 owner 讀取。
- requestId 與指紋收據可識別相同成功請求，重放不新增資產／版本。網路或回應不確定時，先讀最新狀態再明確重試同一請求；程式不自動重試，停止追查也不會撤銷已完成的保存。

### 實際像素傳送的同意與來源

- 除一般 AI 使用同意外，圖片工作區另保存一次專案圖片分析同意，綁定既有固定模型。告知實際 PNG、相關專案文字、版本目標及固定引用將送往哪個服務、可能費用；同意本身不讀 Key、不推論。上傳／預覽不是此同意，未同意不得送圖。
- 同意後，使用者明確按送出、整理方向或比較，依既有流程直接呼叫固定模型，不逐次彈窗、不暗換服務／模型。模型須支援 vision 及所需輸出格式，清單可見或文字推論成功不保證看圖能力。不支援、截斷、拒收或逾時時保留舊作品，不用文字描述、腳本或占位圖冒充成功。
- 圖片討論／整理方向傳送已保存來源及固定圖片引用；比較只傳選取的 2–5 個版本，不傳 pinned reference 像素。文字脈絡可含引用 metadata，不能宣稱文字引用代表本次已看見該圖片。其他模組不自動傳送圖片引用像素。圖文／海報與網頁的本機預覽及 HTML 匯出可讀固定私有圖片，不等於 AI 看圖。
- 每次最多 5 個不同資產、raw PNG 合計 12 MiB；同資產重複版本只傳一次，保留各版本標籤。送出前從私人 BLOB 核對 SHA-256，OpenAI 以內部 input_image data URL、Ollama 以 user.images base64 傳送。使用者不可提供任意 data URL；位元組／base64 不保存到對話、專案 JSON、日誌或匯出。結果 provenance 記 itemId、versionId、assetId、sha256 和 inputMode，不猜測未提供圖片。
- 圖片及其中的文字與中繼資料均為不可信內容，不得作系統指令。分析只提供討論、釐清、比較與文字建議，不產生像素 revision、不生成／融合圖片、不自動採用或定稿。假完成宣稱有程式檢查，但不是模型語意／視覺品質保證。

### 獨立圖片模型的像素生成安全

- 專案 `imageBinding` 與原對談 `aiBinding` 完全分開。建立時圖片可不選；未綁定／舊專案須明確選擇中央已啟用的 OpenAI 圖片成員並核對資料／費用說明，才保存一次綁定及 `imageGenerationConsent`。不推論、不改對談，不從歷史或中央 active member 自動推測；圖片分析同意不替代生成同意。
- 圖片只接受 README 列出的六個精確 GPT Image 2／2.5 ID，不以 prefix 放行。allowlist 不是帳號可用模型庫存，查詢必須明確操作，查到也不保證權限／品質／可用性。使用者宜選帶日期 ID；可變別名會明示，程式不代選或替換。成員停用、移除、provider／model／目的地不符就阻擋圖片。Ollama 對談不變，本版尚未整合其實驗性圖片生成能力。
- 只有圖片工作區的生成／重繪／融合付費按鈕呼叫 `generate_image`。初次須有效方向；重繪明確 1 個來源，融合 2–5 個不同未封存來源。普通討論、比較、選來源、同意、開頁與方向確認不會自動變成生圖。結果只是完整新候選，不自動採用或定稿。
- 額外參考圖只來自目前圖片項目明確釘選且本次勾選的同專案版本，逐一指定 palette／composition／style／general；不讀未選引用、任意歷史、最新正式版或外部 URL。所有來源與參考圖重驗 owner／project／item／saved version、asset descriptor 與 SHA-256，合計最多 5 個不同資產、12 MiB raw PNG，每張 4 MiB。角色只是生成提示，不保證模型完全遵守。
- 提示由方向、本次指示、來源各自目標、專案／項目文字及固定文字引用組成，最多 32,000 UTF-8 bytes，超限拒絕、不截斷；沒有額外 AI 撰寫提示呼叫。圖片文字及引用仍是不可信創作資料，不能授權路由、檔案存取、外部連結或程式執行。使用者應先檢查這些內容適合傳給 OpenAI。
- Images 傳輸固定官方 HTTPS、TLS、無代理／redirect。無圖用 generations JSON，有圖用 edits JSON 的 images data URL，由伺服器建立，不接受使用者提供 URL／路徑。每次固定 1 張、1024×1024、low、PNG、不透明、auto moderation、非串流；沒有自動下一張、品質升級、模型 fallback 或重試。參數契約見 [generate](https://developers.openai.com/api/reference/resources/images/methods/generate) 及 [edit](https://developers.openai.com/api/reference/resources/images/methods/edit)。
- 回應上限 6 MiB，PNG 上限 4 MiB；只保存既有正規化器接受的非交錯 8-bit RGB／RGBA，仍需完整 PNG／CRC／zlib 檢查與記憶體預留，不新增 GD。合法供應商圖片若為不支援格式或過大，或本機保存失敗，可能已計費但無成品；不降低驗證、不存假結果。錯誤不洩漏原始回應／任意供應商錯誤文字或 Key。
- 在呼叫前以既有請求日誌寫 running／消耗 request ID，唯一 owner／ID 與 fingerprint 防本機重放。只有成功回執能重讀結果；running／failed／不明結果不再次發送。資產、新版本、完成收據在同一 SQLite 交易提交，不把網路包進交易。這不保證供應商 exactly-once 或絕不重複計費，逾時、斷線、拒存可能已收費；先讀最新專案／核對用量，再明確決定新請求。
- 歷史保存成員／稱呼、requestedModel、回應確有提供才有的 actualModel、應用／供應商 request ID、固定 options、完整 prompt、來源快照、角色及精確輸入 PNG SHA-256。沒有回應型號就記 null，不編造實際模型；usage 不是帳單。完整提示可能含私人專案文字，分享 JSON 前須檢查。
- Key 沿用原私有暫存 vault，不寫入專案、metadata、日誌或匯出。所有 JSON 仍不包含圖片位元組／base64／data URL；生成 PNG 只存既有私人媒體。PNG 下載與含圖 HTML 可包含真正私人圖片，必須明確操作並遵守既有 owner／CSRF／匯出驗證。圖文、海報、網頁及互動視覺不會因綁定圖片模型就自動生成或傳送像素。

### 匯出、升級與備份

圖片版本可個別下載伺服器保存的 PNG；單件 JSON 只保存中繼資料，專案 JSON 另保留完整歷史，不含 PNG，不是完整圖片備份。完整離線備份須在程式停止寫入時保存整個私有資料夾（含 SQLite 及可能存在的 journal／WAL）與 config.local.php，不只複製使用中的 SQLite 主檔。備份內可能含 Session／暫存 Key，須保密，不能作作品公開分享；目前沒有媒體檔案匯入或自動還原介面。

同系列更新保留原設定、資料庫、私有資料、Cookie／Session 與仍有效的 Key，不重裝、不重設，不會延長 Key 期限。固定腳本示範不提供圖片上傳、私人圖片讀取或真正看圖分析。圖文／海報已提供本機原生排版，離線腳本未提供其示範；互動視覺程式已在正式本機版啟用，但離線腳本明確不提供其示範。

## 圖文／海報的固定圖片與匯出安全

- 圖文／海報使用既有固定文字／結構化模型，不新增圖片 provider，不生成、修改或融合圖片像素。模型輸入的圖片資料採 allowlist，只含標題、替代文字、來源註記、尺寸／MIME 與固定來源識別，明示 pixelsProvided=false；不傳 raw PNG、base64、data URL、資產 descriptor 或 transport 附件。本機私人預覽、資產核對與 HTML 匯出的讀圖，不等於把像素交給模型；實際像素傳送僅限另行明確同意的 image 分析或專用圖片生成流程。
- 原生資料只接受固定主題、排列／對齊、區塊類型及精確欄位。完整 JSON／投影最多 60,000 UTF-8 bytes，圖文 1–24、海報 2–16 區塊，文字、穩定 ID 與語意交叉限制皆前後端驗證。作者標記／網址只作純文字，不接受 HTML、CSS、JS、外部資源、檔案路徑或圖片位元組。純文字排版可以成立，不能以假資產補圖。
- 海報首次方向必須分別確認視覺風格、完整文字內容、圖文排列；後端核對精確有序 [style,text,layout] 與最新 summaryRevision，不只信任前端勾選。新方向使舊確認失效，勾選本身不推論、不保存作品；不能用網頁的三項確認代替。
- 推論／保存前合併目前引用與所選來源歷史，核對 owner 可存取的同專案、確切項目／保存版本、snapshot.id、完整 image artifact 與私人資產雜湊。合法引用 ID、模型 metadata 或合法 JSON 形狀不是存取授權。跨專案／owner、缺圖、資產改動或來源不符均拒絕，不找替代圖、不使用來源最新版本。
- 同一引用 ID 若對應不同來源或快照，前端阻擋編輯器、後端阻擋推論／保存。新版本保留目前引用及作品真正沿用的歷史圖片引用；比較保留所選來源與目前引用的聯集。已保存作品預覽／匯出僅用自身 referencesSnapshot，不從目前引用補缺漏，移除現在的引用不改歷史。明確修訂／融合才追加完整主／小版，不覆寫原件或正式版。
- 模型說明中明顯假稱已看圖的字樣有有界拒收檢查，但不是語意真實性、全語言或視覺品質保證；作品本文不因此被改寫。沒有測試真實 OpenAI／Ollama 的遵循率。內容指紋可拒絕只換 ID／同圖引用別名的假修訂與照抄融合，但不能證明創意品質。
- 編輯欄位、套用草稿與已保存版本分離；未套用欄位須先套用或明確放棄才能新增／移除／重排或另存。欄位跨同頁重畫保留，不寫瀏覽器持久儲存，整頁重整／關閉可能丟失草稿。過期編輯／預覽回呼不能作用於新來源，Blob 預覽按既有規則清理；此編輯器不提供復原堆疊。
- HTML 匯出先固定保存版本、引用及來源，再經既有同源 POST／CSRF 私人介面取 PNG。每張最多 4 MiB，按區塊實際內嵌次數累加最多 20 MiB raw PNG，同圖重複亦計入；HTML 因 base64 與文字可更大。讀取可去重，但容量不能因此少算。匯出重驗 Blob MIME、長度、PNG 簽章／完整區塊／CRC／尺寸及 SHA-256，不接受另一張同大小圖或作者指定的 data URL。
- 每次非同步讀取、arrayBuffer 與 hash 前後都確認目前狀態；缺漏／衝突引用、讀圖失敗、資產不符、取消／stale 皆整筆停止，不建立部分缺圖檔案。只有全部完成才產生下載，不自動重試、忽略圖片或換用較新版本。此流程的 DOM／Blob／crypto 測試替身不是實機瀏覽器安全驗證。
- 輸出 HTML 只包含固定 CSS、安全跳脫文字及程式建立的 PNG data URL。charset 後的早期 CSP 為 default-src none，img-src 僅 data:，style-src 僅固定內嵌樣式的 unsafe-inline，script／connect／object／frame／base／form 禁用；沒有 JS、外部 URL／資源請求或表單。匯出準備會讀本機私有媒體，但輸出檔無需連線，不改主頁 CSP，也不是任意程式沙箱。
- HTML 包含真正的私人圖片、替代文字及來源註記；JSON 僅含 `{notice,artifact}` 與引用 ID，TXT 僅完整文字與引用標記，後兩者不含 PNG 或引用來源快照。所有單版匯出都不含完整專案歷史，不可當完整備份；分享前核對私人內容及圖片授權。沒有匯入／自動恢復介面，不宣稱固定印刷尺寸、單頁列印、上線或外部編輯器相容。
- 離線固定腳本不提供圖文／海報排版流程或私人讀圖，不以假素材或描述冒充成功。互動視覺提供受限資料、原生 Canvas 預覽及可信任 p5.js 主程式匯出；此模組不呼叫獨立圖片模型。

## 互動視覺與 p5.js 匯出安全邊界

- 模型只產生嚴格宣告式 JSON，應用程式只執行既有可信任的 renderer／evaluator。沒有任意 JavaScript／p5.js 原始碼輸入、eval／Function、iframe 沙箱、HTML、外部資源、檔案路徑、網路載入、圖片像素、音訊或 WebGL。標題與圖層／參數 label 原樣作純文字說明，含標記／網址也不解析，不畫成文字圖層。
- 畫布各邊 1–2048 整數、1–40 層 rect／ellipse／line、0–24 個數字參數、播放時間 1–60 整數秒；完整原生 JSON／投影各最多 60,000 UTF-8 bytes。前後端驗證精確欄位、真正型別、有限數字、最多三位小數、穩定 ID、既存目標、唯一 layerId／target、範圍與步進；目前／前次值皆必須合法，超限整筆拒絕，不截斷。
- 02 四項方向確認綁定最新 summaryRevision，只有明確生成才呼叫專案固定模型。動畫與互動可為無；方向確認不是控制項選用、執行或採用作品的同意。生成／修訂／融合沿用固定模型與現有傳送／費用設定，不增加圖片 provider、金鑰或外部執行服務。
- 新參數一律未選用且目前值等於前次值，未選用時不覆蓋圖層原值。只有使用者在編輯器勾選並套用後才能控制數值／滑桿；亂數只改已選用參數。AI 不能改既有 selected、ID 或控制目標，不能刪除已選控制項；未選參數既有數值原樣保留，已選值改動時必須精確保存來源值為 previousValue。模型提示要求僅依本次明確要求改值，但不是自然語言意圖自動驗證，使用者仍須審閱完整候選。
- 融合前檢查同參數的目標、selected、value／previousValue、min／max／step，或同目標不同 ID 的衝突，失敗不呼叫模型、不默選一方；比較仍可檢視各版本取捨。資料指紋用於有界拒收假修訂／照抄融合，不構成像素等價、完整語意或創意品質保證。
- 圖片引用只傳文字中繼資料，沒有 PNG／base64／URL／視覺輸入；圖片項目的看圖同意不放寬此限制。明顯假稱已看圖的說明有有界拒收，但不能證明所有回覆都真實。此互動視覺路徑不生成／修改／融合圖片像素，不會因專案另綁圖片模型而改變。
- 預覽使用原生 Canvas 2D，初次只畫靜態影格。開始、暫停與重設是明確操作；作品時間最多 60 秒／1800 影格，游標另行勾選，與動畫分開。重畫、離頁、移除或頁面隱藏時停止既有動畫；沒有 Canvas 時明確顯示未執行，不以描述代替預覽。這些上限不是實機效能或全平台無障礙保證。
- 只有頂端正式版與編輯器自動建立畫布；其他候選／歷史／引用／比較須明確載入，共用一個額外預覽位置，替換時移除前個 Canvas、取消 RAF 並恢復載入按鈕。mock 的 60 個最大尺寸版本案例初始 2、最多 3 個 live Canvas；這是資源數量契約，不是真實瀏覽器記憶體、GPU 或效能量測。
- 套用、亂數、前次值還原及最近 20 步復原只改頁面草稿，未另存不入歷史。主／小版另存包含完整作品與所有參數狀態；過期回呼及未套用欄位保護不等於持久草稿，整頁重新整理／關閉仍可能遺失。固定引用／採用／定稿維持完整不可覆寫快照。
- 匯出 JS 是固定可信任產生器組裝的 p5.js 主程式，用同一受限 evaluator／painter 與 p5 的 drawingContext；資料字串安全序列化，不讓 title／label 成為可執行來源。程式初始 noLoop，明確開始才播放，游標需另外開啟，參數 setter 只接受已選控制項的合法值。本程式本身不執行這份輸出，也不接收任意 JS 回傳。
- 匯出不含 p5 函式庫或 HTML 容器，使用者須另供可信執行環境；本包沒有 CDN／import／網路自動下載、上傳或部署。外部環境與其載入的程式不在工作室安全邊界內。JSON／TXT 含完整可編輯資料，但沒有匯入 UI；各種匯出可能含私人內容，分享前需檢查，單件匯出不是完整專案備份。
- 主頁 CSP、同源、owner／Session／CSRF 與本機限制不因本功能放寬，沒有新可執行 iframe 端點。離線腳本沒有本類示範；Node VM 中的 p5 替身／Canvas 命令比對不是真正 p5.js、瀏覽器像素、安全認證或外部工具相容性驗收。
