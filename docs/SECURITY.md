# 安全、資料與能力邊界

## 僅本機

本包沒有使用者帳號、團隊管理、多人權限、配額、公開網站防濫用或第三方登入。只接受設定為 localhost/127.0.0.1/[::1] 的網址與真正 loopback 來源，拒絕 Forwarded、X-Forwarded-*、X-Real-IP 等代理標記。Host、Origin、同站來源與 CSRF 均驗證；不提供 CORS。請勿透過隧道、反向代理或區網公開它。

所有讀寫以隨機瀏覽器 owner 限定；這不是完整帳號安全機制。共用電腦的同一瀏覽器代表同一工作者。Cookie/session 遺失沒有帳號復原途徑。

## 金鑰

- 只有專用密碼欄接受既有 OpenAI Key。前端送出前清空欄位，不把 Key 存到 localStorage、sessionStorage、IndexedDB、DOM屬性、狀態物件或作品匯出。
- Key 暫存在網站根目錄外的私有檔案，POSIX 權限目錄0700／檔案0600。Windows 需管理者將 ACL 限定 Apache/PHP 帳號，本程式不能證明系統ACL安全。
- 可用期限30分鐘，每次讀取檢查期限。實體過期檔案在後續請求時才清除，**沒有背景計時刪除，若不再開啟程式，檔案可能仍存在**。用完請主動按清除。
- Key 不寫入 SQLite、設定檔、請求紀錄、錯誤訊息或JSON匯出。請求紀錄只保存雜湊和結果專案識別碼。
- 私有資料夾備份可能包含仍暫存的Key，備份前清除Key。不要分享整個私有目錄。
- AI 成員清單與一次性使用同意只保存非秘密設定，不含 Key；本次工作階段的 OpenAI 成員共用同一份暫存 Key。這份同意不是長期保存金鑰的授權，也不延長 30 分鐘期限。

## AI 連線與費用

OpenAI 目的地固定為官方 HTTPS；驗證憑證、不跟隨重新導向、不使用環境代理。模型清單查詢與連線檢查只讀取模型資訊；生成使用 Responses API、strict JSON Schema、store:false。store:false 不是對 OpenAI 所有服務日誌／保留政策的零保留承諾。

Ollama 只允許同機 HTTP loopback、埠號1024至65535；不允許帳密、任意路徑、查詢、片段或非本機主機。localhost 解析被固定到127.0.0.1，關閉重新導向與代理。只能呼叫固定 `/api/chat` 與 `/api/tags`，不會傳送 OpenAI Key。使用者仍需確保該埠是可信的 Ollama 服務；這不是對另一個本機程式的信任認證。Ollama 自行設定的雲端／轉送服務不在此原型保證範圍。

初次設定需明確勾選並保存資料傳送與費用說明。之後由使用者明確按送出、整理目標、生成、比較或明確融合，直接使用專案初次選定的已啟用成員，不逐次彈窗。這份應用使用同意與創作目標確認分開；沒有同意、沒有啟用成員或尚未選人時阻擋推論。舊設定遷移為「原有設定」成員，使用同意預設為 false，不承襲過去單次請求的同意。新增啟用成員或更換服務、網址、模型時，設定介面要求重新核對並勾選；不是對任意未來目的地的同意。

專案一次選定成員後固定 memberId、稱呼、供應者、模型與 Ollama 位置；舊專案沒有綁定時需明確選定一次，不從中央目前選人偷偷推定。中央移除、停用或改變同一成員的服務／模型／位置會阻擋原專案，不暗中換人。每次請求仍綁定成員 ID、供應者、模型、設定代次及 OpenAI Key 代次，避免在途中設定改變後送到錯誤服務。選擇成員、保存設定、開啟頁面不自動推論，不同時或輪流呼叫多個成員，不自動降級或轉換服務。未知結果、逾時與格式錯誤不自動重試；先查看最新狀態，再決定是否明確建立新請求。

讀取可用模型只由使用者明確按鈕觸發，不自動查詢、下載或推論。清單是服務當次回報的中繼資訊，不保證模型支援所需結構化輸出；手動輸入與最近使用紀錄更不是可用性保證。失敗會顯示原因，不以虛構清單代替。

AI 生成或修訂時，本版目標與修改整理由同一次模型回覆取得，沒有額外摘要呼叫。傳送內容可包含該項目的完整討論、專案脈絡、固定引用及此次操作所需的版本文字與完整表格／圖表／心智圖／向量圖形原生來源；選 OpenAI 即傳送至 OpenAI，選 Ollama 則送到已設定的同機服務。請在操作前確認內容適合交給該服務。

## 內容與來源

- 所有使用者／模型文字用安全文字DOM渲染，不執行HTML、程式或腳本。
- 標題內容 1 至 12 欄，每欄最多 6,000 UTF-8 bytes，合計最多 24,000 bytes；短文為一份完整全文，最多 12,000 bytes。長篇文章 1 至 80 段，每段最多 6,000 bytes、完整保存最多 120,000 bytes；AI 單次生成／融合最多 36,000 bytes，修訂前選段原文最多 24,000 bytes。長文 AI 只回傳明確選段，再由伺服器合併未選原文成完整新版本。「本版目標與修改意見」合併欄位最多 12,000 bytes，比較問題最多 2,000 bytes。舊相容欄位與模型輸出仍保留各自長度驗證；前端提示與後端驗證並行，不把字數當成位元組數。
- 原始 JSON 請求上限為 1 MiB（1,048,576 bytes），容納完整版本及中繼欄位，但不放寬逐欄限制。標題模型脈絡上限為 240,000 bytes，短文／文章／表格／圖表／心智圖／向量圖形為 600,000 bytes；超限停止，不默默截斷歷史。
- 單專案 30 個創作項目，每項 60 版本（含封存）與 60 比較；每個專案序列化內容最多 2,000,000 bytes，並非整個 SQLite 資料庫的總容量上限。
- 比較只接受目前創作項目的 2 至 5 個不同且未封存版本，依各版自己的目標、變更與意見評估，不以目前共用目標排名。回覆必須逐一匹配所選 ID，不接受 AI 憑空替換版本；缺少歷史記錄不事後捏造。
- 正式版只是明確選定的指標；主版本、小版本、AI 候選及手動保存都追加完整快照，不覆寫原內容、ID 或來源。候選封存只改項目層的封存 ID 清單；正式版不能封存，還原不刪改歷史。定稿與專案結案各有獨立明確操作。
- AI 成員有穩定 ID。新回覆、版本及比較固定當時成員稱呼、供應者、要求／實際模型；停用或改名不重標歷史，舊資料缺欄位不以現設定補造。
- 明確融合保存所選版本的完整直接內容、目標與來源；內嵌來源的更早融合只保留版本 ID 關係，不遞迴複製祖先樹。融合不代表採用或定稿。
- 跨創作項目引用固定完整版本，來源改動不會更新引用。生成版本也保存當時引用快照、共享脈絡及模型來源，便於追溯。
- 專案名稱／說明、項目名稱／說明或引用變動後，新一批生成與定稿需重新整理及確認目標；既有正式版可在保留失效標記的情況下繼續修訂。比較使用各版本已保存的目標，不要求目前目標已確認，也不假造目標同意。已定稿項目需先重新開啟才能改動。

## 表格／圖表安全與匯出界線

- 表格以真正的 columns／rows／cells 儲存，所有格子是文字，不執行公式、HTML 或腳本。原生作品只接受指定欄位，列欄 ID 唯一、每列格數一致；前後端各驗證，伺服器以 artifact 重新產生文字投影，不信任客戶端另傳的內容摘要。
- 流程圖使用受限 Mermaid 風格語法與自製 SVG，不載入 Mermaid／CDN 或執行來源文字。只接受明確節點、箭頭、純文字標籤及支援的方向，拒絕初始化指令、子圖、class／style、click、HTML、Markdown、圖片、網址及任意程式。來源經解析後才用固定 SVG 元素／屬性生成預覽；文字用 textContent，匯出進行 XML 跳脫，不加入外部資源或連結。
- 流程圖最多 40 節點、80 連線；允許循環／自我連線，但排版不作無界走訪。這是有限簡化圖形能力，不是任意 Mermaid 的安全沙箱，也不保證完整 Mermaid 或圖坊相容。完整節點與連線另以文字列表顯示，圖面縮略不改來源。
- 統計圖只接受有界 TSV，1–5 數列、1–24 列資料，數值為有限十進位、絕對值不超過 1 兆；公式與非數字拒收。不得為湊圖捏造未提供的數據，也不得把固定示範資料當作使用者的事實。
- 表格最多 12 欄、100 列，每格 2,000 bytes；圖表來源最多 12,000 bytes；兩者完整 artifact JSON 及文字投影各最多 60,000 bytes。超限或不合法輸出拒收，不略過有問題的部分假裝成功。大容量仍受專案總量與模型輸出預算限制。
- 生成、候選微調、手動保存及融合都追加完整 typed artifact，不覆寫來源；固定引用與定稿包含完整原件。只有明確採用才變更正式版，來源不會因外部資料或後續版本自動同步。
- CSV／TSV 匯出為以 `=`、`+`、`-`、`@`、Tab／CR／LF 起頭的文字，以及以一般空白後接公式符號的文字，加前置單引號降低試算表公式注入風險。已驗證的統計數值欄保留數字，包括負數；這不保證所有第三方試算表匯入設定都安全。原始文字仍在 JSON，分享與匯入前應自行檢查。
- 匯出與剪貼簿只能由明確按鈕觸發，操作已保存版本；不呼叫 AI、不上傳或同步到外部工具。CSV／TSV、MMD 與 SVG 不含完整版本／來源關係，不能當成專案備份；專案 JSON 可能包含私人文字、流程與統計，分享前需檢查。

## 向量圖形安全與保存邊界

- 向量是嚴格原生資料，不接受任意 SVG／XML、HTML、CSS、JavaScript、path、貝茲曲線、圖片、外部 URL、字型、濾鏡或漸層。預覽／匯出只建立已知 SVG 元素與固定屬性；文字使用安全 DOM 與 XML 跳脫，不執行文字中的標記。
- 原始 JSON schema 在轉換前核對真正物件／陣列、有限數字、整數與上下限，不把數字字串、布林值或 null 當數值。語意層另驗證全部精確欄位、全圖唯一穩定 ID、幾何類型及其跨欄位要求。六位十六進位色碼／none 以外的填色或外框拒收，不能透過 url() 載入資源。
- 1–100 個物件，畫布寬高各為 1–4096 整數；座標／局部頂點 -4096 至 8192，物件寬高／線段位移 -8192 至 8192，矩形／橢圓寬高須正值。外框寬度 0–100、不透明度 0–1、文字大小 1–512，數值最多三位小數。超精度或超限拒收，不默默四捨五入或截斷；多邊形 3–80、折線 2–80 個頂點，其餘類型不得夾帶頂點。
- 標題最多 600、物件名稱 120、文字內容 4,000 UTF-8 bytes；完整原生 artifact JSON 與緊湊投影各最多 60,000 bytes。伺服器仍核對最終序列化位元組數，PHP 非預設 serialize_precision 可能使其更嚴，不把前端通過當成保存保證。投影由 artifact 重新生成，不信任客戶端另送文字。
- 欄位輸入、已套用草稿及已保存版本分開。尚未套用欄位在同頁重畫、物件切換及狀態讀取時保留，但不寫 localStorage／sessionStorage，也不是持久保存。整頁重新整理或關閉會失去未另存內容；20 步復原僅屬目前頁面草稿。未套用內容須先套用或明確放棄，才可進行會丟字的操作及外層另存。
- 修訂、融合、手動主／小版、比較來源、固定引用、正式版及定稿保存完整原生作品與來源；只有明確採用改正式版。AI 使用已保存來源，不讀頁面草稿；釐清須回傳相同作品後捨棄。融合拒絕與任一來源相同的繪製資料，名稱、ID 或等值色碼大小寫改動不能冒充新融合；圖層順序與重複物件仍有意義。
- SVG 匯出保留獨立原生幾何與文字，不內嵌點陣圖。通用字型由本機軟體決定，不保證其他工具字型或排版相同；超出畫布的物件只在顯示時裁切，原生資料仍保留。JSON／TXT 保存完整原生資料，均可能包含私人文字，分享前需檢查。單件匯出不含完整版本歷史，不能取代專案 JSON 備份。
- 匯出只由明確按鈕處理已保存版本，不呼叫 AI、不上傳或同步至外部工具。使用者所稱「形坊」的目前名稱與匯入規格尚未核對，不保證匯入相容性，沒有外部連接器或雙向同步。

## 未涵蓋

不保證能抵抗本機管理員、惡意瀏覽器擴充、作業系統入侵、受污染的PHP或Ollama程式。沒有檔案上傳、圖片生成、網站部署、任意程式執行、多人登入或公共API金鑰資助。

完整公開上線需要另外設計權限、身份、配額、審計、資料治理、HTTPS、速率限制及部署安全。這次沒有完成那些工作，也沒有將此包公開部署。本次未執行原生 PHP／Apache／XAMPP、實機瀏覽器或真實 OpenAI／Ollama 驗收；來源、模擬與契約檢查不能替代這些測試。
