# 安全、資料與能力邊界

## 僅本機

本包沒有學生帳號、教師管理、多人權限、配額、公開網站防濫用或校務登入。只接受設定為 localhost/127.0.0.1/[::1] 的網址與真正 loopback 來源，拒絕 Forwarded、X-Forwarded-*、X-Real-IP 等代理標記。Host、Origin、同站來源與 CSRF 均驗證；不提供 CORS。請勿透過隧道、反向代理或區網公開它。

所有讀寫以隨機瀏覽器 owner 限定；這不是完整帳號安全機制。共用電腦的同一瀏覽器代表同一工作者。Cookie/session 遺失沒有帳號復原途徑。

## 金鑰

- 只有專用密碼欄接受既有 OpenAI Key。前端送出前清空欄位，不把 Key 存到 localStorage、sessionStorage、IndexedDB、DOM屬性、狀態物件或作品匯出。
- Key 暫存在網站根目錄外的私有檔案，POSIX 權限目錄0700／檔案0600。Windows 需管理者將 ACL 限定 Apache/PHP 帳號，本程式不能證明系統ACL安全。
- 可用期限30分鐘，每次讀取檢查期限。實體過期檔案在後續請求時才清除，**沒有背景計時刪除，若不再開啟程式，檔案可能仍存在**。用完請主動按清除。
- Key 不寫入 SQLite、設定檔、請求紀錄、錯誤訊息或JSON匯出。請求紀錄只保存雜湊和結果專案識別碼。
- 私有資料夾備份可能包含仍暫存的Key，備份前清除Key。不要分享整個私有目錄。

## AI 連線與費用

OpenAI 目的地固定為官方 HTTPS；驗證憑證、不跟隨重新導向、不使用環境代理。連線檢查只讀取模型資訊；生成使用 Responses API、strict JSON Schema、store:false。store:false 不是對 OpenAI 所有服務日誌／保留政策的零保留承諾。

Ollama 只允許同機 HTTP loopback、埠號1024至65535；不允許帳密、任意路徑、查詢、片段或非本機主機。localhost 解析被固定到127.0.0.1，關閉重新導向與代理。只能呼叫固定 `/api/chat` 與 `/api/tags`，不會傳送 OpenAI Key。使用者仍需確保該埠是可信的 Ollama 服務；這不是對另一個本機程式的信任認證。Ollama 自行設定的雲端／轉送服務不在此原型保證範圍。

每次推論都需使用者明確確認，綁定供應者、模型、設定代次及 OpenAI Key代次。更換模型不自動生成，不自動降級或轉換服務。未知結果、逾時與格式錯誤不自動重試；需要先查看最新狀態，再決定是否以新請求操作。

## 內容與來源

- 所有使用者／模型文字用安全文字DOM渲染，不執行HTML、程式或腳本。
- 每組1至12個項目、每項內容最多6000 UTF-8 bytes，整組最多24000 bytes。單專案30個創作項目、每項60版本與60比較；每個專案序列化內容最多2,000,000 bytes，並非整個SQLite資料庫的總容量上限。
- 比較只接受目前創作項目的2至5個有效版本，回覆必須逐一匹配，不接受AI憑空替換版本。
- 正式版只是明確選定的指標；候選與手動保存都追加，不覆寫原快照。定稿與專案結案各有獨立明確操作。
- 跨創作項目引用固定完整版本，來源改動不會更新引用。生成版本也保存當時引用快照、共享脈絡及模型來源，便於追溯。
- 專案名稱／說明、項目名稱／說明或引用變動後，新一批生成／比較／定稿需重新整理及確認目標；既有正式版可在保留失效標記的情況下繼續修訂，不假造目標同意。已定稿項目需先重新開啟才能改動。
