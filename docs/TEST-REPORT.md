## 已實際執行

- **167 項 Node 測試通過，0 失敗、0 跳過。**
  - 106 項前端／DOM／固定腳本回歸：直接執行 production renderer、事件處理與 fetch adapter，但 DOM 是測試替身，不是真實瀏覽器。新增固定專案模型與舊專案一次性選定、無逐句切換、方向準備完成與明確確認生成、指定候選接續微調、文章選段完整快照、短文全文、手動段落結構修改、原文空白保存、版本樹、獨立比較與融合、來源壓縮、選項與草稿／未知結果保護。
  - 40 項原有後端來源契約回歸：Host／Origin／CSRF、暫存 Key、owner 隔離相關來源、固定目的地、請求重放、版號與逐版目標、引用、成員與來源快照等。
  - 7 項模組來源契約：十二種類型順序、前三種文字啟用、文字容量／完整性、同次回覆提供方向、原始 JSON 嚴格 schema、文章選段合併、單次完整生成與融合。
  - 8 項共用流程來源契約／容量計算：不可暗換專案模型、確認才生成、精確來源／選段、融合直接快照不遞迴膨脹、兩家 adapter 的輸出上限參數、全文保存與剩餘容量、準備方向的儲存預留。
  - 6 項實際 fetch 序列化回歸：32 條 POST 路由、JSON body.action／CSRF／Content-Type、GET 開啟、錯誤與不重試、最壞 JSON 跳脫的標題及完整 120,000-byte 文章，在 1 MiB envelope 內完整傳輸。接收端是契約替身，不是 PHP HTTP server。
- **Python SQLite 實際執行 SQL：12 項檢查通過。** 建表、寫入與 owner 隔離、讀取、請求唯一性、非破壞初始化、成員設定遷移及 compare-and-swap。不是 PHP PDO 整合測試。
- **28 份 PHP 檔案通過 Pygments 詞法／括號結構檢查。** 不是 PHP parser、php -l 或 runtime。
- JavaScript 語法檢查通過。原有可見文字對背景色數值對比檢查仍通過；不是整頁無障礙或視覺認證。
- 靜態審查已修正融合祖先快照重複展開、手動文字空白被 trim、OpenAI 輸出 token 參數漏宣告，以及近全文容量時模型收到錯誤段落輸出預算等問題。

完整輸出見 [test-results.txt](test-results.txt)。來源契約只能證明所檢查程式片段及計算條件存在，不能代替執行 PHP。
