# AI共創工作室：HTTP 安裝與本機驗收

## 環境與邊界

- PHP 7.4 以上，相容語法目標 7.4；新安裝宜使用仍維護的 PHP 版本。
- JSON、PDO SQLite、cURL、Session、zlib、雜湊、隨機權杖與檔案鎖可用，SQLite 3.24 以上。
- 圖片正規化使用 PHP zlib，不要求 GD。PHP `file_uploads` 須開啟、`upload_max_filesize` 至少 4M、`post_max_size` 至少 5M；主 JSON API 仍維持 1 MiB，圖片端點只接受 4 MiB PNG 加少量中繼資料。
- 保留合理的 `memory_limit`。程式會保守預留 PNG 解壓／壓縮及模型 raw／base64／JSON／cURL 副本空間，可用記憶體不足或無法確認時拒絕，不自動提高限制。符合 4 MiB／2048 像素也不保證每台主機能處理；請縮小圖片／減少分析張數，不要關閉限制。
- Apache 可服務完整資料夾；`public/` 是入口，`app/`、`docs/`、`tests/` 附拒絕存取規則。其他主機必須只公開 `public/`。
- 僅能在 PHP 主機同一台電腦使用 localhost、127.0.0.1 或 [::1]，不支援公開部署、區網多人、代理或隧道。
- 本文件描述第四階段：圖文與海報原生排版的本機來源，不代表已部署；遠端版本與 GitHub ZIP 內容請以實際 commit 核對。
- 本次沒有原生 PHP runtime，以下是安裝／待驗收步驟，不是 PHP、Apache／XAMPP、實機瀏覽器或真實模型已通過紀錄。

## 全新安裝，不需命令列

1. 完整解壓至 `C:/xampp/htdocs/ai-cocreation-series-php74`。從 GitHub Download ZIP 取得的資料夾可改成此名稱，或相應調整本機網址。
2. 從 XAMPP 控制台啟動 Apache，同機瀏覽器開啟 `http://localhost/ai-cocreation-series-php74/public/`，進入一次性安裝頁。
3. 依頁面檢查 PHP 與擴充；不足時由主機管理者啟用並重新啟動 Apache。
4. 私有資料夾可填 `C:/private/ai-cocreation-series-data`，不得在 htdocs、專案或公開 Apache Alias 內。若 PHP 無權建立，先由檔案總管建立，僅授予 Apache／PHP 帳號所需寫入權。
5. 網址須與安裝頁一致，末尾保留 `/`。完成後建立不含 Key 的 `config.local.php`，安裝自動鎖定，不覆寫既有資料。
6. 可收回 Apache 對程式根目錄的寫入權，保留私有資料夾可寫入。

安裝不需要 API Key，也不呼叫 AI。初始 OpenAI 模型欄位不代表已驗證帳戶可用性；完成後在系統設定管理成員。可先看明確標示的固定腳本示範，但它不是真實模型。

## AI 設定與專案綁定

在「系統設定」配置成員稱呼、服務、模型與啟用狀態，閱讀並勾選資料傳送／費用說明。新增啟用成員或更換服務、模型、網址需重新核對同意；保存設定本身不推論。

建立專案時一次選定 AI 成員／模型，專案內所有項目固定使用，不提供對話間切換。沒有啟用成員時可先建立未綁定空專案，完成設定後須明確綁定一次；舊未綁定專案同樣處理。已綁定後，原成員停用／移除或服務、模型、網址不符會阻擋，須恢復原設定；需要另一模型請另建專案，不自動 fallback。歷史與固定綁定不隨中央改名而重標。

有使用同意後，明確送出、生成、比較或融合即使用固定模型，不逐次彈窗；建立／綁定專案、開頁面及保存設定不推論。模型清單及連線檢查需明確按鈕操作，只讀中繼資訊，不下載或推論，也不證明格式、品質、效能可用。

### OpenAI

在專用密碼欄輸入自己的既有 Key，不要放在對話或作品。Key 不回顯、不存在瀏覽器、成員清單、SQLite、設定或匯出，於 Web root 外私有工作階段暫存最多 30 分鐘；該工作階段的 OpenAI 成員共用，保存使用同意不延長期限。API 計費與 ChatGPT 訂閱分開。

模型查詢讀取目前 Key 可見資訊。受限 Key 的中繼資訊查詢可能出現 403，不代表所有生成權限都無效；請核對專案權限，不關閉 TLS 驗證。查到模型不保證它支援 Responses／結構化輸出或圖片視覺輸入。

### Ollama

須已在 PHP 主機同機啟動並安裝模型，預設網址 `http://127.0.0.1:11434`，模型欄填實際名稱。localhost 指 PHP 執行機。本包不安裝 Ollama、不下載模型、不調整系統網路權限。

查詢／檢查使用 `/api/tags`，推論固定 `/api/chat`、JSON Schema、非串流，只允許 loopback HTTP。OpenAI Key 不會傳給 Ollama。不相容或截斷輸出明確拒收、保留舊資料，不換模型或填示範答案。兩家 6,000–24,000 output tokens 是路徑請求預算，不保證模型一定支援或產出指定字數。

### 圖片分析的額外同意與模型能力

圖片上傳、預覽與下載不呼叫 AI、不需要 Key。要分析圖片，在圖片工作區明確同意一次將實際 PNG、版本目標、固定引用與相關專案文字送給目前專案固定服務；同意綁定該模型，不立即呼叫 AI。之後按送出／整理方向／比較即執行，不逐次彈窗。服務可能收費，Ollama 自行設定的轉送亦不在本包保證範圍。選定模型必須支援視覺與所需結構化輸出；不相容時不改用其他模型、不假稱已看圖。

圖文／海報不需要上述圖片分析同意才能進行文字排版：它們只把文字與已釘選圖片中繼資料送給原固定模型，不傳像素、不新增圖片服務。私人預覽與含圖 HTML 匯出只讀取本機已保存圖片，不呼叫 AI。要使用圖片素材，先在同專案圖片項目明確保存，再於排版項目加入特定版本引用。

## 第一次本機驗收清單

以下推論步驟需自行決定是否執行，OpenAI 可能產生費用；不是本次已完成的實測。第 3–7 步的生成／AI 修改／融合適用文字與原生作品類型；圖片依下方專用清單，不得當成完整生圖流程驗收。

1. 查看固定腳本示範並辨識其標示；正式頁建立兩個專案，選定模型，確認名稱、說明、模型綁定互相獨立。
2. 同一專案建立各類項目，確認十一類功能各有獨立歷史。圖片只開放上傳與分析；圖文／海報提供原生排版而不產圖。互動視覺程式仍未啟用，不能生成或定稿。
3. 一次提供足夠方向，確認 AI 同次回覆可整理待確認主軸，不強制三輪、不自動生成。再試缺必要資訊時只問一個重點。明確按「確認方向並生成候選」後才生成。
4. 確認標題一次 3–5 組、短文 3 篇全文，文章／表格／圖表／心智圖／向量圖形／網頁／圖文／海報各 1 份完整候選；心智圖初次只有根與另列待選分支；正式版置頂，下方標示 01 對談、02 主軸與方向、03 候選。
5. 不採用先選候選微調，再試從正式版微調；應各自沿真正來源另存小版本，來源與正式版指標不變。文章須明確選段，未選就阻擋；檢查 AI 可參考全文而未選段落原文字節與順序保持不變，結果保存完整文章。
6. 手動保存文章可新增／移除／改名段落，AI 選段不可擴大範圍；分別另存主版、小版，檢查完整內容、目標、ID、來源。版本樹可展開主版與內容，顯示實際父來源，不把所有小版串成假鏈。
7. 選 2–5 版比較，確認逐版依自身目標說明，不統一排名或改作品；另明確融合，應只增一個完整主版候選、保存全部來源及取捨，正式版不變。
8. 採用標題名稱會同步更新創作項目名稱；採用短文／文章／表格／圖表／心智圖／向量圖形／圖片／網頁／圖文／海報不因此更名，專案名稱／說明一律保持。只有明確操作才定稿或結案。
9. 測試候選封存／還原、其他項目固定引用、來源改版及重新開啟，舊歷史完整且正式版不能封存。已封存規劃項目不阻擋其他已完成項目結案。
10. 改中央成員稱呼，確認歷史與專案綁定不重標；暫停原成員或變更模型／網址，確認原專案阻擋且不改用其他成員，恢復原設定後才能延續。未綁定舊專案必須明確選一次。
11. 測試超長輸入、過大選段、失效選項與舊分頁 revision，應明確阻擋，不截斷、覆蓋新資料或自動重試。確認 1 MiB HTTP 與 2,000,000 bytes 專案限制，細項見[架構](ARCHITECTURE.md)。

心智圖另請人工驗收（尚非本次實測結果）：

- 主題起步：只提供主題即可進入待確認方向，不強制先選唯一主軸；確認生成前不建候選。初次只有根與 2–12 個未勾選待選分支，SVG 不含待選分支。

- 編輯與草稿：名稱／說明先套用、自填子節點先加入，再另存；切換節點與介面重畫保留未套用文字，保存／合併／移除／復原不應悄悄丟字。檢查最近 20 步草稿復原，來源及正式版保持不變。

向量圖形另請人工驗收（尚非本次實機測試結果）：

- 原生作品：確認候選是一份含獨立矩形、橢圓、線段、多邊形、折線與文字的原生資料，而不是圖片、SVG 字串或文字描述；不需要另設圖片服務，仍使用專案固定文字／結構化模型。

- 未套用欄位：同頁切換物件、讀取最新狀態及忙碌重畫不應丟字，錯誤數值保留以便修正；尚未處理的欄位阻擋新增、複製、重排、移除、復原及另存。整頁重新整理／關閉不保留未另存草稿，不要把同頁狀態重新讀取當成持久保存。

- 容量與格式：1–20 區塊、cards／faq 每區 1–12 條目，真正 boolean 導覽開關、完整原生正規 JSON 及文字投影最多 60,000 UTF-8 bytes。額外欄位、任意程式或外部 URL 作為按鈕目標、錯誤型別與超限應拒收，不轉型、不截短。
- 匯出：已保存版本 HTML 使用固定 CSS、跳脫文字與早期 CSP，無 JS 或外部資源請求，保留頁內導覽與 FAQ；在桌面／窄螢幕、鍵盤及實際下載後逐項核對。JSON 保留可編輯原生資料、TXT 保存相同 JSON；沒有 HTML／JSON 檔案匯入介面，匯出不等於部署。這些瀏覽器行為仍待本機實測。
- 固定腳本：選「使用網頁示範」或輸入「請使用網頁示範。」，三項確認後看到虛構街角故事日。只支援明確格式的標題、單一區塊文字、固定主題及導覽開關；衝突或不支援要求不假稱完成。沒有外部圖片／字型／連結、表單、登入、付款、API、任意 HTML／CSS／JS 或部署，網頁功能本身不放寬工作室 CSP／新增 iframe 執行端點；圖片功能只另加 img-src blob: 供私人預覽。

圖片另請人工驗收（尚非本次 PHP／瀏覽器／真實視覺模型測試結果）：

- 本機準備：選靜態 PNG／JPEG，驗證原檔 12 MiB、每邊 8192、總像素 16,777,216 上限；假 MIME、損壞、尾隨資料及 SVG／GIF／WebP／APNG 應拒收。選檔、旋轉及取消不得送出網路請求或呼叫 AI，原檔不改，檔名不自動填入標題。
- 方向與透明度：使用含方向資訊的 JPEG、透明 PNG，檢查解碼方向及額外 0／90／180／270 度順時針旋轉；副本不放大、最長邊 2048、上限 4 MiB。請在實際瀏覽器目視檢查，測試替身不能驗證 canvas 像素。副本與下載不保證保留原檔色彩管理，EXIF／IPTC／XMP 及 profiles 會移除。
- 明確上傳：先填圖片標題與本版目標，再保存主版；已有來源時另試小版。核對只有明確保存才上傳、連按不重複提交、原版本及正式版不變；新圖片版本明示外部上傳，不偽造 AI provenance。可在沒有 Key 的情況下保存。
- 伺服器拒收：直接傳送非 PNG、調色盤／交錯／非 8-bit RGB／RGBA、APNG、tRNS、錯 CRC、解壓列長錯誤、過大及非法 PNG，均應拒收，不依瀏覽器檢查或 MIME 判定。zlib 不可用／記憶體 headroom 不足時安全阻擋，不降低驗證。
- 私人讀取：只有頂端正式版自動讀圖，其他候選／歷史／引用／比較須按「載入此圖片預覽」，不應開頁就下載全部歷史圖。預覽／下載必須由同源 POST、CSRF、owner、專案、項目及確切已保存版本核對，GET 或另一 owner／錯誤 item／descriptor 不可取得 PNG。固定引用與封存／定稿舊版應仍讀原資產；重畫／關閉／失敗時 Blob URL 釋放，過期回應不移入新項目。
- 文字與歷史：圖片標題、替代文字、來源註記先套用再另存完整主／小版，asset 不可變；要換像素必須重新上傳。未套用欄位不被當成版本。核對封存／還原、正式版、固定引用與定稿保留原圖片；沒有自動清理歷史資產。
- 原子性與容量：模擬 stale revision、錯 active item、配額或保存失敗，資產、版本與收據不可只存其中一部分；同一 requestId／fingerprint 重放不得新增版本，異內容同 ID 拒收。每專案 100 張／64 MiB、每 owner 400 張／256 MiB，封存不釋放額度。
- 中斷：上傳失敗或未知結果時保留同頁本機副本及文字；先讀最新紀錄，再明確重試同一請求。不在背景重送、不宣稱已失敗就必然沒存；切換項目／專案前須保存或取消，其他分頁切換後不得把副本存到錯誤項目。
- 固定模型分析：先核對一次圖片傳送範圍，同意不呼叫 AI；之後普通送出直接使用專案固定模型，不重複彈窗。討論來源加固定圖片引用會傳真正 PNG；比較只傳所選 2–5 版，引用像素不混入。每次最多 5 個不同資產、合計 12 MiB raw PNG，超限或記憶體不足應於傳送前拒絕。
- 分析來源：核對結果 provenance 含 item／version／asset／SHA-256，實際 request 的 PNG 與已保存版本一致。純圖片分析只增加討論／比較，不建假圖片版；不支援 vision 的模型應失敗且不換模型。其他類型的固定圖片引用目前只有 metadata 脈絡，不假稱已傳像素。
- 方向與能力：按「確認圖片方向（不生成圖片）」不推論、不生成。生成／像素修訂／融合按鈕不可執行，直接 API 也拒絕；可明確採用與定稿外部圖片。圖文／海報請另按下方排版清單驗收；互動程式仍為規劃。
- 匯出與備份：個別下載 PNG 並核對最終雜湊；專案 JSON 的圖片只含中繼資料，須有不完整圖片備份警語，不含 raw／base64。要保留全歷史媒體，程式停止寫入後離線備份整個私有資料夾及設定，不只複製執行中的 SQLite 主檔；敏感備份不分享。
- 示範：固定腳本不得提供圖片上傳、私人圖片讀取或真正看圖分析，不用固定圖片描述冒充模型成功。

圖文與海報另請人工驗收（尚非本次 PHP／瀏覽器／真實模型測試結果）：

- 範圍：登錄十一類啟用，圖文與海報各有獨立歷史；互動視覺程式仍未啟用。離線固定腳本不提供這兩類生成或私人圖片流程，不能用假結果代替正式頁驗收。
- 固定素材：同專案先保存外部圖片，再明確加入確切版本引用。無圖片時可產生合法純文字排版，不應自造圖片／網址。跨 owner／專案／項目、錯版本、缺失或被改動資產應在推論／保存前拒絕；不得自行換成較新圖。
- 海報方向：在 02 分別核對視覺風格、完整文字內容、圖文排列；單獨勾選不推論、不保存。缺項、重複、錯序、網頁三項或過期 directionRevision 應拒絕；新方向清除舊勾選，全部確認後明確生成才新增一份完整候選。
- 原生內容：圖文完整段落、標題、圖說及 text／above／left／right，paper／night／meadow；海報 headline／text／image、left／center／right、portrait／square／landscape 及 paper／night／festival。檢查完整長文字與夜色文字、圖說、私人圖片說明的閱讀效果；海報可延展，不驗收為固定印刷尺寸或單頁列印。
- 編輯：作品設定與區塊欄位先套用或明確放棄，再新增／移除／上下移動及另存完整主／小版。保留穩定 ID；未套用欄位在區塊切換、busy 重畫或同頁狀態讀取後仍在，不將草稿當保存版本。整頁重新整理可能失去草稿，沒有排版復原堆疊；過期編輯事件不得改新來源或其他項目。
- 固定快照：移除目前引用後，從使用該圖的舊版繼續微調，應保留原歷史固定圖。新保存版含目前引用及實際沿用歷史圖；比較保存所選來源引用聯集。同一引用 ID 對應不同版本快照時，應阻擋編輯／推論／保存，不猜測選用。來源後續改版或封存不更改舊排版。
- 模型資料：核對請求只有文字、原生排版與 allowlist 圖片中繼資料、pixelsProvided=false，沒有 PNG／base64／URL。圖片分析同意不改變排版模組的 metadata-only 邊界。明顯假稱已檢視像素的模型說明應拒收，但此字樣檢查不是語意或模型品質保證；真實模型行為仍須人工審閱。
- 完整歷史：候選／正式版修訂、手動主／小版、2–5 版比較／明確融合、固定引用、採用及定稿皆保留完整 artifact、各版目標與模型來源。純釐清、僅換 ID／同圖引用別名不應建立假修改；融合不是像素合成，不自動覆寫正式版。
- 私人預覽：只有正式版自動載入；其他版按「載入此排版圖片預覽」，草稿按「載入編輯草稿圖片預覽」。不開頁就下載全部歷史圖片，不把本機顯示當成模型看圖；讀取仍走同源 POST／CSRF 和精確保存版本。
- HTML 完整性：從已保存版按「下載完整排版 HTML」，核對 PNG 格式、尺寸、長度及 SHA-256，圖像必須來自該版 referencesSnapshot。改目前引用不得影響舊版匯出；缺圖、衝突、hash 不符、讀取失敗或切換頁面使操作過期時，不下載缺圖檔案。合法純文字排版可正常匯出而無假圖片。
- HTML 容量／安全：每張 PNG 最多 4 MiB，按所有區塊內嵌次數累計 20 MiB；同圖重複不得少算。HTML 因 base64 可更大。離線打開檔案應保留完整文字、固定主題及內嵌圖，無 script／外部資源請求／表單，作者標記與網址只作文字。另在桌面／窄螢幕、鍵盤與真實下載後核對；來源及 fake DOM 不代表已驗證這些行為。
- 匯出區分：JSON 只含原生 artifact 與固定引用 ID，TXT 只含文字，均不含 PNG 或來源完整版本；HTML 也不含完整歷史。沒有檔案匯入／自動還原介面，分享前檢查真正內嵌圖片及私人內容；完整備份仍須停止寫入後保存私有資料夾與設定。
