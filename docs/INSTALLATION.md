# HTTP 安裝與本機驗收

## 環境

- PHP 7.4 以上，相容語法目標為 7.4；新安裝建議使用仍維護的 PHP 版本。
- JSON、PDO SQLite、cURL、Session、隨機權杖與檔案鎖可用；SQLite 3.24 以上。
- Apache 可服務完整資料夾。`public/` 是入口；`app/`、`docs/`、`tests/` 附拒絕存取規則。若使用非 Apache 主機，管理者必須只公開 `public/`。
- 只能在 PHP 主機同一台電腦開啟 `localhost`、`127.0.0.1` 或 `[::1]`。本包不支援區網多人連線。

## 不使用命令列的安裝

1. 完整解壓到 `C:/xampp/htdocs/ai-cocreation-series-php74`。
2. 從 XAMPP 控制台啟動 Apache。
3. 用瀏覽器開啟 `http://localhost/ai-cocreation-series-php74/public/`，自動進入一次性安裝頁。
4. 安裝頁檢查 PHP 與擴充。缺少時用 XAMPP 控制台／設定編輯器啟用，再重新啟動 Apache。
5. 私有資料夾填 `C:/private/ai-cocreation-series-data`。不能在 `htdocs`、專案或公開 Apache Alias 內。若 PHP 無權建立，使用檔案總管建立，僅授予 Apache/PHP 帳號寫入權。
6. 網址必須與目前開啟的安裝頁一致；末尾保留 `/`。完成後建立不含密鑰的 `config.local.php`，安裝自動鎖定，不會覆寫既有資料。
7. 可收回 Apache 對程式根目錄的寫入權，保留私有資料夾可寫入。

安裝不呼叫 AI、不需要 API Key。安裝頁預設欄位僅指定初始 OpenAI 模型，不代表已查證帳戶可用模型；完成後可在系統設定配置 OpenAI／Ollama 成員。

## 設定 AI 成員

在「系統設定」建立成員稱呼，選服務與模型，勾選要啟用的成員並保存。對話區只列已啟用成員，需選定一位；沒有啟用或尚未選人會阻擋 AI 操作，不自動替換。

第一次需閱讀並明確勾選資料傳送與費用說明。保存後，明確按送出、整理目標、生成或比較，就直接呼叫所選成員，不逐次彈窗。設定、切換成員與開頁面不會推論；每次只呼叫選定的一位。使用同意是非秘密設定，與 OpenAI Key 暫存分開。新增啟用成員或更換服務、網址、模型時，需重新核對並勾選；單純切換已同意成員不會逐次詢問。

「讀取模型清單」只在明確按鈕後查詢，不會開頁面就查詢。查詢失敗可檢查權限／服務，或自行填入已知模型名稱；手動名稱及最近輸入紀錄不等於服務回報清單。

### OpenAI

為成員選 OpenAI、填模型，再在專用密碼欄貼自己的既有 Key。Key 不回顯，不保存在瀏覽器或成員清單，最長暫存 30 分鐘，本次工作階段的 OpenAI 成員共用這份 Key；保存使用同意不延長期限。保存設定不代表已驗證金鑰。

模型清單查詢讀取目前 Key 可見的模型，「檢查連線」讀取指定模型資訊，兩者不做推論。清單可見不代表所有模型皆支援 Responses／結構化輸出。有些受限 Key 沒有模型資訊讀取權限，可能出現 403；這不等於所有生成權限都無效，請檢查專案權限。不要在一般對話貼金鑰，也不要關閉 TLS 驗證。

### Ollama

Ollama 必須已在 PHP 主機同一台電腦啟動，且已有模型。預設網址 `http://127.0.0.1:11434`，模型欄請填實際安裝名稱。`localhost` 指 PHP 執行機，不是別台電腦上的瀏覽器。本包不安裝 Ollama、不下載模型、不改系統網路權限。

模型清單查詢及連線檢查讀取 `/api/tags`；清單來自該次服務回應，連線檢查另確認所填模型存在，均不載入模型推論。實際創作使用 `/api/chat`、JSON Schema 與非串流回覆。不相容模型可能無法遵守格式，會明確報錯並保留舊資料，不改用其他模型。

## 第一次驗收

1. 先跑固定腳本示範，清楚辨識它不是 AI。
2. 在正式頁建立兩個專案，確認名稱與說明分開保存。
3. 同一專案建立兩個「標題名稱」項目，確認各自有獨立對話與候選。
4. 設定至少一位啟用的 AI 成員並完成一次性同意。明確送出一則短對話，確認沒有逐次同意彈窗，且標籤對應成員稱呼／供應者／模型。這一步可能產生 OpenAI 費用。
5. 三輪後整理／確認目標並生成候選組，確認所有已同意及既有欄位完整。工作區不應再出現巢狀「新增內容項目」，專案層新增功能仍在。
6. 選一版手動編輯本版目標與意見，分別另存主版本和小修改，確認整組完整、版號與實際來源正確，舊版及正式版不自動變動。
7. 升一版為正式版，提出明確修改，檢查新的待採用小版本及差異；採用後再修改，確認從新正式版延續。
8. 選 2–5 版比較，檢查依各版自己的目標與意見，而非目前同一目標排名。讓目前目標待確認後，再確認比較仍可使用；新候選與定稿仍有目標門檻。
9. 封存候選並還原，確認正式版不能封存，歷史不改。另在其他項目固定引用來源版本，來源後來改版或封存時引用應不變。
10. 改成員稱呼、停用成員並切換選人，確認歷史快照不重標、停用成員不出現在對話選單、無有效選擇時不呼叫。模型清單只在明確按鈕後查詢。
11. 項目定稿、重新開啟、項目封存／還原及專案結案，確認歷史完整。

以上是待在自己的本機完成的驗收步驟，不是本次已通過的實測紀錄。本次未執行 PHP、Apache、真實瀏覽器、OpenAI 或 Ollama 模型驗收，包含 `php tests/versioning.php` 與 `php tests/members.php` 在內的 PHP fixture 均未執行。已跑檢查請見 [測試報告](TEST-REPORT.md)。

## 備份與更新

- 程式更新前停止寫入，備份作品資料庫、程式與不含金鑰的 `config.local.php`，排除暫存 Key／Session 檔。若要備份整個私有資料夾，先在設定中清除 Key，以免把憑證一起備份。單純覆蓋程式不需要重新輸入仍有效的 Key；超過原 30 分鐘期限則依原規則重新提供。將新版程式合併覆蓋到原根目錄；不要先刪整個舊資料夾，不覆蓋設定或私有資料，不重新安裝、不刪資料庫。
- 保留原網址、原瀏覽器 Cookie／Session。本版前端快取標籤為 `20261021-version6`；更新後重新整理，仍看到舊介面時強制重新整理，不以清除 Cookie 排除快取問題。
- 原有 Vn 讀作主版本 Vn，原 ID、內容與來源保留，不補造未曾保存的目標／討論。舊單一 AI 設定轉成「原有設定」成員，需首次勾選使用同意後才能推論；不必重新建立專案或重裝。
- 對話與內容屬於同一瀏覽器工作階段。Cookie／session 遺失後，沒有帳號復原入口；重要資料請用匯出功能另存。
- JSON 匯出包含創作文字、版本、引用與模型來源，不含 Key；檔案可能含你的個人或未公開內容，分享前自行檢查。
- Key 檔案與 Session 不適合當作作品匯出一起傳送；一般作品分享應使用介面匯出，不是打包整個私有資料夾。

## 資料格式邊界

本版支援同一「專案 → 多創作項目」系列的既有版本更新，保留原設定與資料；不是要求既有使用者換資料夾重裝。它不提供舊藝術共創室、台詞／分場系統或開發中單項目版資料庫的跨產品遷移。只有從這些其他系統另行安裝時，才需使用新的獨立私有資料夾，不要指向其他系統的資料。不承諾所有未來資料格式均可直接覆蓋升級。
