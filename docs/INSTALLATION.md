# AI共創工作室：HTTP 安裝與本機驗收

## 環境與邊界

- PHP 7.4 以上，相容語法目標 7.4；新安裝宜使用仍維護的 PHP 版本。
- JSON、PDO SQLite、cURL、Session、zlib、雜湊、隨機權杖與檔案鎖可用，SQLite 3.24 以上。
- 圖片正規化使用 PHP zlib，不要求 GD。PHP `file_uploads` 須開啟、`upload_max_filesize` 至少 4M、`post_max_size` 至少 5M；主 JSON API 仍維持 1 MiB，圖片端點只接受 4 MiB PNG 加少量中繼資料。
- 保留合理的 `memory_limit`。程式會保守預留 PNG 解壓／壓縮及模型 raw／base64／JSON／cURL 副本空間，可用記憶體不足或無法確認時拒絕，不自動提高限制。符合 4 MiB／2048 像素也不保證每台主機能處理；請縮小圖片／減少分析張數，不要關閉限制。
- Apache 可服務完整資料夾；`public/` 是入口，`app/`、`docs/`、`tests/` 附拒絕存取規則。其他主機必須只公開 `public/`。
- 僅能在 PHP 主機同一台電腦使用 localhost、127.0.0.1 或 [::1]，不支援公開部署、區網多人、代理或隧道。
- 本文件描述第七階段：固定雙模型與圖片生成、重繪、融合的本機來源，不代表已部署；遠端版本與 GitHub ZIP 內容請以實際 commit 核對。
- 本次沒有原生 PHP runtime，以下是安裝／待驗收步驟，不是 PHP、Apache／XAMPP、實機瀏覽器或真實模型已通過紀錄。

## 全新安裝，不需命令列

1. 完整解壓至 `C:/xampp/htdocs/ai-cocreation-series-php74`。從 GitHub Download ZIP 取得的資料夾可改成此名稱，或相應調整本機網址。
2. 從 XAMPP 控制台啟動 Apache，同機瀏覽器開啟 `http://localhost/ai-cocreation-series-php74/public/`，進入一次性安裝頁。
3. 依頁面檢查 PHP 與擴充；不足時由主機管理者啟用並重新啟動 Apache。
4. 私有資料夾可填 `C:/private/ai-cocreation-series-data`，不得在 htdocs、專案或公開 Apache Alias 內。若 PHP 無權建立，先由檔案總管建立，僅授予 Apache／PHP 帳號所需寫入權。
5. 網址須與安裝頁一致，末尾保留 `/`。完成後建立不含 Key 的 `config.local.php`，安裝自動鎖定，不覆寫既有資料。
6. 可收回 Apache 對程式根目錄的寫入權，保留私有資料夾可寫入。

安裝不需要 API Key，也不呼叫 AI。初始 OpenAI 模型欄位不代表已驗證帳戶可用性；完成後在系統設定管理成員。可先看明確標示的固定腳本示範，但它不是真實模型。

## AI 設定與專案綁定

在「系統設定」配置成員稱呼、服務、模型與啟用狀態，閱讀並勾選資料傳送／費用說明。新增啟用成員或更換服務、模型、網址需重新核對同意；保存設定本身不推論。

建立專案時一次選定固定對談成員／模型，另可選擇固定圖片成員，不預選、不強制純文字專案綁定圖片。兩者在專案內各自共用，不提供逐句／逐次切換。沒有啟用成員時可先建立未綁定空專案，完成設定後須明確綁定一次；舊未綁定專案同樣處理。已綁定後，原成員停用／移除或服務、模型、網址不符會阻擋，須恢復原設定；需要另一模型請另建專案，不自動 fallback。歷史與固定綁定不隨中央改名而重標。

有使用同意後，明確送出、生成、比較或融合即使用固定模型，不逐次彈窗；建立／綁定專案、開頁面及保存設定不推論。模型清單及連線檢查需明確按鈕操作，只讀中繼資訊，不下載或推論，也不證明格式、品質、效能可用。

### OpenAI

在專用密碼欄輸入自己的既有 Key，不要放在對話或作品。Key 不回顯、不存在瀏覽器、成員清單、SQLite、設定或匯出，於 Web root 外私有工作階段暫存最多 30 分鐘；該工作階段的 OpenAI 成員共用，保存使用同意不延長期限。API 計費與 ChatGPT 訂閱分開。

模型查詢讀取目前 Key 可見資訊。受限 Key 的中繼資訊查詢可能出現 403，不代表所有生成權限都無效；請核對專案權限，不關閉 TLS 驗證。查到模型不保證它支援 Responses／結構化輸出或圖片視覺輸入。

### 固定圖片模型與付費前的設定檢查

圖片模型是專案的另一份固定綁定，不替換對談模型。中央成員須已啟用、服務為 OpenAI，且 ID 精確符合 [README 六個受支援模型](../README.md#固定雙模型與支援的圖片模型)。宜自行選帶日期 ID；別名可由供應商更新。支援清單與模型查詢不保證這份 Key 的帳號權限、配額或實際可用性，不自動補造清單、下載模型或付費試跑。

新專案的圖片成員預設不選，可留空；舊專案／未綁定專案須在圖片工作區明確選一次，核對真正 PNG、相關文字送往 OpenAI 及額外費用，再按「同意並固定圖片模型（不生成圖片）」。綁定與保存同意不呼叫 AI，不改 `aiBinding`；圖片分析同意與生成同意不可互代。原成員改動／停用／移除會阻擋原圖片綁定，不能暗換另一模型。

原有 Key vault、30 分鐘期限與本機邊界不變，不新增長期儲存或要求把 Key 寫進設定。Images API 每次固定單張 1024×1024、low、不透明 PNG；PNG 最多 4 MiB，只接受既有非交錯 8-bit RGB／RGBA 正規化。服務合法但不支援的 PNG 格式或本機存取失敗仍可能已計費，請先閱讀[使用指南](USER-GUIDE.md)與[安全限制](SECURITY.md)。本次沒有取得或使用真實 Key，沒有付費測試。

### Ollama

須已在 PHP 主機同機啟動並安裝模型，預設網址 `http://127.0.0.1:11434`，模型欄填實際名稱。localhost 指 PHP 執行機。本包不安裝 Ollama、不下載模型、不調整系統網路權限，也尚未接上其實驗性圖片生成；不代表 Ollama 永遠不能產圖，既有固定 Ollama 對談不變。

查詢／檢查使用 `/api/tags`，推論固定 `/api/chat`、JSON Schema、非串流，只允許 loopback HTTP。OpenAI Key 不會傳給 Ollama。不相容或截斷輸出明確拒收、保留舊資料，不換模型或填示範答案。文字／結構化作品的兩家 6,000–24,000 output tokens 是路徑請求預算，不保證模型一定支援或產出指定字數。

### 圖片分析的額外同意與模型能力

圖片上傳、預覽與下載不呼叫 AI、不需要 Key。要分析圖片，在圖片工作區明確同意一次將實際 PNG、版本目標、固定引用與相關專案文字送給目前專案固定服務；同意綁定該模型，不立即呼叫 AI。之後按送出／整理方向／比較即執行，不逐次彈窗。服務可能收費，Ollama 自行設定的轉送亦不在本包保證範圍。選定模型必須支援視覺與所需結構化輸出；不相容時不改用其他模型、不假稱已看圖。

圖文／海報與網頁不需要上述圖片分析同意才能進行文字與固定圖片排版：它們只把文字與已釘選圖片中繼資料送給原固定模型，不傳像素、不新增圖片服務。私人預覽與含圖 HTML 匯出只讀取本機已保存圖片，不呼叫 AI。要使用圖片素材，先在同專案圖片項目明確保存，再於排版項目加入特定版本引用；網頁亦可明確引用圖文／海報固定版本中的實際用圖，不自動跟隨最新正式版。

## 第一次本機驗收清單

以下推論步驟需自行決定是否執行，OpenAI 可能產生費用；不是本次已完成的實測。第 3–7 步的共用流程適用文字與原生作品；圖片生成、重繪、融合依下方獨立專用清單驗收，不能把 mock 或文字分析當成真實生圖通過。

1. 查看固定腳本示範並辨識其標示；正式頁建立兩個專案，選定模型，確認名稱、說明、模型綁定互相獨立。
2. 同一專案建立各類項目，確認十二類功能各有獨立歷史。圖片只開放上傳與分析；圖文／海報提供原生排版而不產圖；互動視覺提供受限幾何、動畫／游標互動與參數選用，不是任意程式執行。
3. 一次提供足夠方向，確認 AI 同次回覆可整理待確認主軸，不強制三輪、不自動生成。再試缺必要資訊時只問一個重點。明確按「確認方向並生成候選」後才生成。
4. 確認標題一次 3–5 組、短文 3 篇全文，文章／表格／圖表／心智圖／向量圖形／網頁／圖文／海報／互動視覺各 1 份完整候選；心智圖初次只有根與另列待選分支；正式版置頂，下方標示 01 對談、02 主軸與方向、03 候選。
5. 不採用先選候選微調，再試從正式版微調；應各自沿真正來源另存小版本，來源與正式版指標不變。文章須明確選段，未選就阻擋；檢查 AI 可參考全文而未選段落原文字節與順序保持不變，結果保存完整文章。
6. 手動保存文章可新增／移除／改名段落，AI 選段不可擴大範圍；分別另存主版、小版，檢查完整內容、目標、ID、來源。版本樹可展開主版與內容，顯示實際父來源，不把所有小版串成假鏈。
7. 選 2–5 版比較，確認逐版依自身目標說明，不統一排名或改作品；另明確融合，應只增一個完整主版候選、保存全部來源及取捨，正式版不變。
8. 採用標題名稱會同步更新創作項目名稱；採用短文／文章／表格／圖表／心智圖／向量圖形／圖片／網頁／圖文／海報不因此更名，專案名稱／說明一律保持。只有明確操作才定稿或結案。
9. 測試候選封存／還原、其他項目固定引用、來源改版及重新開啟，舊歷史完整且正式版不能封存。已封存規劃項目不阻擋其他已完成項目結案。
10. 改中央成員稱呼，確認歷史與專案綁定不重標；暫停原成員或變更模型／網址，確認原專案阻擋且不改用其他成員，恢復原設定後才能延續。未綁定舊專案必須明確選一次。
11. 測試超長輸入、過大選段、失效選項與舊分頁 revision，應明確阻擋，不截斷、覆蓋新資料或自動重試。確認 1 MiB HTTP 與 2,000,000 bytes 專案限制，細項見[架構](ARCHITECTURE.md)。

表格與圖表另請人工驗收（尚非本次實測結果）：

- 流程圖：預設 flowchart，採用[使用指南](USER-GUIDE.md)語法範例檢查 TD／LR、節點、判斷、標籤、循環與文字列表；錯誤格式應明確拒收。SVG 是自製簡化預覽，不是完整 Mermaid 引擎。MMD／複製應對應已保存來源，不含未另存草稿。
- 統計模式：用自行提供的 TSV 核對長條／折線／圓餅圖；缺資料不應捏造，非法數字、重複分類、錯誤欄數應拒收。切換流程／統計模式必須保留原來源，不能自動清空或改成假資料。
- 對表格與圖表候選分別微調、手動另存、比較、融合、固定引用、明確採用及定稿，核對完整 artifact 貫穿所有快照；引用來源後續改版不會自動替換。未按採用時正式版不變。
- 固定腳本中明確選「使用流程圖示範」或輸入「請使用流程圖示範。」；也可選虛構參觀人次統計。確認內容標示虛構／非 AI，不解析真實流程／數據，也不宣稱已驗證圖坊匯入。

心智圖另請人工驗收（尚非本次實測結果）：

- 主題起步：只提供主題即可進入待確認方向，不強制先選唯一主軸；確認生成前不建候選。初次只有根與 2–12 個未勾選待選分支，SVG 不含待選分支。
- 明確入圖：選候選微調，單純點節點或勾 checkbox 不改 artifact；按「將勾選分支加入草稿」後才改草稿，未勾選的仍待選，外層另存後才增加完整版本。設正式版不會自動接受其餘建議。
- 編輯與草稿：名稱／說明先套用、自填子節點先加入，再另存；切換節點與介面重畫保留未套用文字，保存／合併／移除／復原不應悄悄丟字。檢查最近 20 步草稿復原，來源及正式版保持不變。
- 整理：移動保持子樹、拒絕根／自己／後代；合併保留來源名稱與說明，轉移子節點及待選分支。容量超限整筆拒絕；有子節點或待選分支的節點不能當空末端移除。
- AI 子分支：先保存新加入節點，再於對談區選來源及目標。AI 只更新目標待選集合，已入圖節點與其他父節點待選內容原樣保存。pending-only／不存在目標、失效選項或錯誤來源在推論前阻擋；沒有內容或目標實質變動時不造假版本。
- 完整歷史：逐一核對主／小版、比較、融合、固定引用、正式版與定稿；融合不能提升待選建議為已入圖節點，不能改寫原來源。JSON／TXT 包含清楚分開的已入圖及待選內容，SVG 只畫已入圖樹。匯出不含尚未另存草稿、不推論。
- 固定腳本：使用「請使用心智圖示範。」與「請提供這個節點的子分支示範。」測試虛構待選流程。它不解析真實主題；重複、無法辨識、衝突融合不得假稱完成。相關操作不等於真實 AI 已驗收。

向量圖形另請人工驗收（尚非本次實機測試結果）：

- 原生作品：確認候選是一份含獨立矩形、橢圓、線段、多邊形、折線與文字的原生資料，而不是圖片、SVG 字串或文字描述；不需要另設圖片服務，仍使用專案固定文字／結構化模型。
- 編輯與草稿：選取不改圖；修改座標、尺寸／局部頂點、名稱、色彩、文字與畫布後，須先套用再另存。檢查新增、同位置複製、前後圖層、移除、最近 20 步草稿復原；既有物件 ID 不變，新物件使用新 ID。
- 未套用欄位：同頁切換物件、讀取最新狀態及忙碌重畫不應丟字，錯誤數值保留以便修正；尚未處理的欄位阻擋新增、複製、重排、移除、復原及另存。整頁重新整理／關閉不保留未另存草稿，不要把同頁狀態重新讀取當成持久保存。
- 數值與界線：1–100 物件、整數畫布 1–4096、最多三位小數；數字字串／布林／非有限數字、超精度、非支援色彩與原始 SVG 應拒收，不默默轉型、四捨五入或截短。多邊形／折線頂點數、文字長度及 60,000-byte 原生／投影總量仍需本機核對，非預設 PHP 序列化精度可能更早達到後端上限。
- 完整流程：從候選與正式版各微調，逐一核對主／小版、各版目標、比較、明確融合、固定引用與定稿的完整 artifact；純討論、名稱／ID／色碼大小寫的假融合不應建立新圖形，原來源及正式版不改。AI 只讀已保存來源，不含頁面草稿。
- 匯出：已保存版本的 SVG 應含獨立圖形與文字，而不是內嵌點陣圖；JSON／TXT 保留完整原生幾何、文字及圖層，專案 JSON 另留共創歷史。瀏覽器下載、文字呈現及使用者既有工具的匯入仍須實測；「形坊」目前名稱與規格尚未確認，不宣稱相容。
- 固定腳本：輸入「請使用向量圖形示範。」並確認，應看到虛構晨光書屋；選來源後測試逐字標題或指定物件填色／外框色修改。不得解析任意真實設計要求，衝突、重複或無法辨識時不假稱完成。外部字型／圖片、path／貝茲曲線、JS／CSS、任意 SVG 匯入均非本版能力。

- 草稿與歷史：畫布／圖層／參數欄位先套用或放棄，再另存完整大版或小版。未套用字串跨同頁重畫保留，並阻擋會丟字的操作；過期回呼不能改新項目。最近 20 步復原不改保存歷史。新版本包含全部圖層、順序、參數 selected／value／previousValue，正式版不自動取代。
- 原生預覽：初次只畫第一影格，不自動播放或啟用游標。明確開始／暫停／重設，作品時間最多 60 秒／1800 影格；切換項目、重畫、頁面隱藏及離頁時舊迴圈停止。游標需另勾選，pointer／hover 與動畫分開；確認取消游標後立即停止影響。實際尺寸、滑鼠／觸控、鍵盤、效能與無障礙仍須瀏覽器人工驗收。
- 預覽數量：只有頂端正式版與編輯草稿自動建立 Canvas；候選、歷史、固定引用及比較區須明確載入，並共用一個額外預覽位置。載入另一份時應移除前份 Canvas、停止 RAF、還原其載入按鈕；不可因展開版本樹就建立全部畫布。60 個 2048×2048 版本的 mock 檢查是初始 2、最多 3 個 live Canvas，不是真實瀏覽器記憶體量測。
- AI 範圍：只讀已保存來源與圖片中繼資料，不讀草稿、不傳圖片像素、不執行模型 JS。新參數未選用，既有選用／目標不得被模型改動；已選值只應按本次要求修改並保存精確前次值。AI 不可移除已選控制項；需先由使用者取消選用、套用並另存。
- 比較／融合：各版依自己的目標比較，未選參數不可當成畫面已生效。融合前同 ID 的目標、選用、值／前次值、範圍／步進衝突，或同目標不同 ID，應在呼叫模型前拒絕，仍可比較。僅換名稱、ID、標籤或未選參數不應冒充融合；指紋不是像素等價或創意品質驗收。
- p5 匯出：匯出已保存版 JS／JSON／TXT，不採用未保存草稿。JS 是可信任產生器輸出的 p5.js 主程式，不含模型可執行碼、CDN／import／網路自動請求；須另外自行提供可信 p5.js 函式庫及執行頁面。核對 setup 的初始 noLoop、明確播放、獨立游標開關與已選參數 setter。真正 p5 runtime、瀏覽器下載與跨環境像素尚未驗證，不把 Node 替身當作通過。
- 外部工具：官方 [createCanvas](https://p5js.org/reference/p5/createCanvas/) 與 [noLoop](https://p5js.org/reference/p5/noLoop/) 僅作選讀說明，不自動傳作品、連帳號或部署；互動視覺模組沒有任意 p5.js 匯入／編輯／執行，也不呼叫獨立圖片模型；圖片 API 沿用既有暫存 Key，不新增金鑰保存流程。

## 同系列既有安裝：安全覆蓋更新

1. 停止所有寫入，離線備份原程式、`config.local.php` 及完整私有資料夾，包括 SQLite 及可能存在的 journal／WAL 檔；不要只複製使用中的主資料庫。備份可能含有效 Key／Session，須私密保管，不得當作品分享。更新本身不要求清除或重填目前 Key。
2. 將新版原始碼合併覆蓋至原程式根目錄。不要先刪整個舊資料夾、重新安裝、覆蓋 `config.local.php`／私有資料、刪除或重設資料庫。
3. 保留原網址及瀏覽器 Cookie／Session。前端快取標籤為 `20261021-version17`，重新整理，仍是舊介面時強制重新整理；不要清除 Cookie 當作清快取。升級本身不要求重設模型或重填 Key；目前仍有效的 Key 與 Session 保留；自行清除或到期的 Key 仍依原有暫存規則，在需要使用 OpenAI 時重新提供，不承諾升級後永久保留。
