# HTTP 安裝與本機驗收

## 環境

- PHP 7.4 以上，相容語法目標為 7.4；新安裝建議使用仍維護的 PHP 版本。
- JSON、PDO SQLite、cURL、Session、隨機權杖與檔案鎖可用；SQLite 3.24 以上。
- Apache 可服務完整資料夾。`public/` 是入口；`app/`、`docs/`、`tests/` 附拒絕存取規則。若使用非 Apache 主機，管理者必須只公開 `public/`。
- 只能在 PHP 主機同一台電腦開啟 `localhost`、`127.0.0.1` 或 `[::1]`。本包不支援區網教室多人連線。

## 不使用命令列的安裝

1. 完整解壓到 `C:/xampp/htdocs/ai-cocreation-series-php74`。
2. 從 XAMPP 控制台啟動 Apache。
3. 用瀏覽器開啟 `http://localhost/ai-cocreation-series-php74/public/`，自動進入一次性安裝頁。
4. 安裝頁檢查 PHP 與擴充。缺少時用 XAMPP 控制台／設定編輯器啟用，再重新啟動 Apache。
5. 私有資料夾填 `C:/private/ai-cocreation-series-data`。不能在 `htdocs`、專案或公開 Apache Alias 內。若 PHP 無權建立，使用檔案總管建立，僅授予 Apache/PHP 帳號寫入權。
6. 網址必須與目前開啟的安裝頁一致；末尾保留 `/`。完成後建立不含密鑰的 `config.local.php`，安裝自動鎖定，不會覆寫既有資料。
7. 可收回 Apache 對程式根目錄的寫入權，保留私有資料夾可寫入。

安裝不呼叫 AI、不需要 API Key。安裝頁預設欄位僅指定初始 OpenAI 模型；完成後可在系統設定改選 Ollama。

## 選擇 AI

### OpenAI

在「系統設定」選 OpenAI、模型，再在密碼欄貼自己的既有 Key。Key 不回顯，也不保存在瀏覽器。保存設定不代表已驗證金鑰。

「檢查連線」只讀取該模型資訊，不做推論。有些受限 Key 沒有模型資訊讀取權限，可能出現 403；這不等於所有生成權限都無效，請檢查你的專案權限。不要在一般對話貼金鑰，也不要關閉 TLS 驗證來排除連線問題。

### Ollama

Ollama 必須已在 PHP 主機同一台電腦啟動，且已有模型。預設網址 `http://127.0.0.1:11434`，模型欄請填實際安裝名稱。`localhost` 指 PHP 執行機，不是別台電腦上的瀏覽器。本包不安裝 Ollama、不下載模型、不改系統網路權限。

連線檢查讀取 `/api/tags`，確認所填模型存在；不載入模型推論。實際創作時使用 `/api/chat`、JSON Schema 與非串流回覆。較小／不相容模型可能無法遵守格式，會明確報錯並保留舊資料。

## 第一次驗收

1. 先跑固定腳本示範，清楚辨識它不是 AI。
2. 在正式頁建立兩個專案，確認名稱與說明分開保存。
3. 同一專案建立兩個「標題名稱」項目，確認各自有獨立對話與候選。
4. 真實 AI 測試需你明確點擊並確認。先完成一次短對話，再檢查對應的供應者與模型標籤。
5. 三輪後整理／確認目標，生成候選組，手動新增一個自訂欄位保存新版本。
6. 升一個版本為正式版，再生成或比較，確認正式版不會自動改變。
7. 在另一項目引用該固定版本；改動來源後，確認引用仍保留原快照。
8. 項目定稿、重新開啟、封存／還原、專案結案，確認歷史完整。

## 備份與更新

- 程式更新前停止寫入，備份完整私有資料夾與不含金鑰的 `config.local.php`。保留原設定，不重新安裝或刪資料庫。
- 對話與內容屬於同一瀏覽器工作階段。Cookie／session 遺失後，沒有帳號復原入口；重要資料請用匯出功能另存。
- JSON 匯出包含創作文字、版本、引用與模型來源，不含 Key；檔案可能含你的個人或未公開內容，分享前自行檢查。
- Key 檔案與 Session 不適合當作作品匯出一起傳送；一般作品分享應使用介面匯出，不是打包整個私有資料夾。

## 資料格式邊界

這是「專案 → 多創作項目」架構的第一個發行包，不提供舊藝術共創室、台詞／分場系統或開發中單項目版資料庫的自動遷移。請使用新的獨立私有資料夾，不要指向其他系統的資料。日後更新同格式版本仍應先完整備份；不承諾所有未來資料格式均可直接覆蓋升級。
