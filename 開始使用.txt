第一次安裝：
1. 把完整資料夾解壓到 XAMPP 的 htdocs，名稱使用 ai-cocreation-series-php74。
2. 從 XAMPP 控制台啟動 Apache，用同一台電腦開啟：
   http://localhost/ai-cocreation-series-php74/public/
3. 依網頁環境檢查完成安裝。私有資料夾建議 C:/private/ai-cocreation-series-data，
   不可在 htdocs、專案或公開 Alias 裡。安裝不需要金鑰，也不呼叫 AI。
4. 可先開啟「固定腳本示範（非 AI）」了解操作；不是模型驗收，重新整理會重設。
5. 在系統設定配置 AI 成員稱呼、OpenAI／Ollama、模型及啟用狀態，閱讀並勾選資料傳送與費用說明。
   OpenAI：只在專用密碼欄輸入既有 Key，Web root 外私有工作階段暫存最多 30 分鐘，API 費用另計。
   Ollama：須已在 PHP 主機同機啟動且有模型，預設 http://127.0.0.1:11434。
6. 建立專案時一次選好 AI 成員／模型，專案各項目固定共用，不逐句換人。
   若尚無啟用成員而先建立空專案，或開啟舊未綁定專案，完成設定後須明確綁定一次。
   原成員被移除、停用或模型／目的地變更時會阻擋，請恢復原設定；要換模型請另建專案。
7. 模型清單只在按鈕操作後查詢，也可手填名稱。不自動查詢、推論或下載；查到模型不保證輸出格式或品質。

基本操作：
建立專案並固定模型 → 新增／選取創作項目 → 對談 → 閱讀主軸與方向
→ 明確按「確認方向並生成候選」→ 微調、比較或明確融合 → 自行設正式版 → 項目定稿 → 專案結案。

正式版完整內容置頂，下方為 01 對談、02 主軸與方向、03 候選。
方向足夠時 AI 在同次討論回覆主動整理，不限定三輪；不足才釐清必要資訊。方向備妥不會自動生成。
標題名稱一次 3–5 組候選，短文 3 篇；長篇文章、表格、圖表、心智圖、向量圖形、網頁每次各 1 份完整候選。
候選不必先採用就能選為微調來源；AI 修改另存小版本，手動可另存主版本或小版本，都保存完整快照。
短文以「全文」完整修改；長篇文章先選來源，再勾選要請 AI 改的段落。
AI 看見全文但只修改選段，未選段落逐位元組保留，合併保存完整新文章，不預設全選。
手動完整文章編輯可新增、移除或改名段落；AI 選段修訂不能偷偷改段落結構。
「本版目標與修改意見」只用一欄，隨各版本保存；比較與修訂優先依各版自己的紀錄。
版本樹可展開主版與完整內容，顯示小版、實際修改來源及融合來源，不以相鄰版號猜來源。
比較與融合為獨立操作，各需選 2–5 個未封存版本。融合另存一個新主版本候選，不自動採用。
只有標題名稱採用正式版時同步更改創作項目名稱；短文／文章／表格／圖表／心智圖／向量圖形／網頁不因此更名，專案資料一律不變。
封存不刪資料或釋放容量，正式版不能封存；固定引用、來源與過往定稿保持不變。
模型不自動重試、切換服務或替換成示範答案。結果未知時先讀取最新狀態，拒收也可能已計費。

表格與圖表：
- 表格有真正的列、欄與儲存格，可新增／移除列欄、改欄名與文字；不執行公式。
- 圖表預設為流程圖。編輯安全受限的 Mermaid 風格來源，立即預覽本程式產生的 SVG，另有完整節點／連線文字列表。
  首行 flowchart TD 或 flowchart LR；節點各占一行，例如 A["整理想法"]、B{"確認？"}、C("開始")。
  連線另占一行，例如 A --> B 或 B -->|是| C；所有端點都要有獨立宣告，不支援完整 Mermaid、HTML、網址或任意程式。
- 長條／折線／圓餅是可選統計模式，需提供實際 TSV 數據，不得捏造；流程圖不需要統計數字。
  切換模式不清除／轉換來源，格式不符時修正後才能保存。
- 候選微調、手動保存、融合、固定引用與定稿都保留完整結構快照，不自動採用。
- 已保存版本可匯出：表格 CSV／TSV，流程圖 MMD／SVG，統計圖 TSV／SVG；圖表也可按「複製文字來源」。
  未驗證圖坊匯入相容性，不會自動連線或同步。CSV／TSV 可疑公式文字會加前置單引號；完整原文、結構及歷史另存專案 JSON。
- 固定腳本中選「使用流程圖示範」，或輸入「請使用流程圖示範。」；內容是明確標示的虛構流程，不解析你的資料、不是 AI。
  也可明確選虛構參觀人次統計示範。對話只逐字替換指定標題／說明或本版目標；其他內容請在編輯器修改另存。

向量圖形實際操作：
1. 先說明用途與必要內容，確認方向後產生一份完整候選。沿用專案固定文字／結構化模型，不另接圖片服務。
2. 以候選繼續微調，選取矩形、橢圓、線段、多邊形、折線或文字，修改座標、尺寸／頂點、名稱、色彩及文字。
   可改畫布大小與背景、新增／複製／移除物件或調整前後圖層；沒有拖曳、自由路徑或貝茲曲線。
3. 先按「套用畫布修改至草稿」或「套用圖形修改至草稿」，最後另存完整主／小版本。
   同頁切換物件、讀取最新狀態或忙碌重畫會保留未套用欄位；整頁重新整理或關閉會失去未另存草稿。
   尚未套用的欄位須先套用或明確放棄，不能偷偷當成已保存內容；可復原最近 20 步草稿操作。
4. AI 只讀已保存來源；修訂、比較與融合都保留完整原生作品及各版自己的目標，不自動改正式版。
5. 已保存版本可匯出 SVG／JSON／TXT。SVG 保留可編輯幾何及文字，JSON／TXT 保留原生資料；完整歷史另用專案 JSON。
   沒有任意 SVG 匯入、外部圖片／字型、JavaScript／CSS 或自動外部同步。「形坊」目前名稱與匯入規格尚未驗證。
6. 固定腳本可輸入「請使用向量圖形示範。」；確認後是虛構的晨光書屋圖案，不是 AI 或你的真實設計。
   來源微調只示範逐字指令，例如：標題改為「晨光書屋｜探索版（虛構示範）」。
   或：將「晨光」的填色改為「#ef8354」。作品標題不會改寫圖內文字；其他修改請用手動編輯器。

網頁實際操作：
1. 先談用途與材料，AI 會整理「視覺風格」「內容結構」「操作功能與限制」三部分。
   分別閱讀並勾選後，才按「確認方向並生成候選」。勾選本身不呼叫 AI、不保存作品；方向更新須重新勾選。
2. 一次生成一份原生響應式網頁，支援 paper／midnight／meadow 三種固定風格，
   hero 主視覺、text 文字、cards 卡片、faq 問答及 cta 行動區。按鈕只在本頁跳轉，FAQ 可展開收合。
3. 以候選或正式版繼續微調，可改網頁設定、區塊與卡片／問答的完整文字及順序。
   欄位先明確套用至草稿，再另存完整主／小版；未套用內容須先套用或放棄，可復原最近 20 步草稿操作。
   同頁切換區塊、忙碌重畫及讀取狀態保留欄位草稿，整頁重新整理／關閉會失去未另存內容。
4. AI 只讀已保存來源。可明確引用同專案其他項目的固定版本作為內容材料，不會自行抓取或隨來源改版自動更新。
   比較、融合、固定引用與定稿保留完整作品及模型來源；只有明確採用才改正式版。
5. 已保存版本可匯出獨立 HTML、原生 JSON 或 TXT。HTML 使用固定 CSS 與跳脫後的純文字，無腳本或外部資源請求；
   保留頁內導覽及可展開 FAQ。JSON 保留可編輯資料，TXT 是相同原生 JSON 的純文字檔，目前沒有檔案匯入按鈕。
6. 不支援任意 HTML／CSS／JavaScript、外部圖片／字型／連結、表單送出、登入、付款、API 或部署。
   網址文字也不會變成外部連結。匯出不等於上線，工作室仍僅本機使用，不是任意程式碼沙箱。
7. 固定腳本輸入「請使用網頁示範。」並逐項確認，可試用虛構街角故事日網頁，不是真實 AI。
   可逐字輸入：標題改為「街角故事日｜探索版（虛構示範）」。或：視覺主題改為「midnight」。

主要限制（UTF-8 位元組，不是中文字數）：
- 標題名稱 1–12 欄，每欄 6,000、合計 24,000。
- 短文固定全文一欄，最多 12,000。
- 長篇文章 1–80 段，每段 6,000、完整保存合計 120,000。
  單次 AI 生成／融合最多 36,000；AI 修訂選段原文合計最多 24,000，回傳選段合計最多 36,000，且須在全文剩餘容量內。
- 表格 1–12 欄、1–100 列，每格 2,000、欄名 120、說明 600；完整 JSON 及文字投影各最多 60,000。
- 圖表標題 600、各軸標籤 120、來源 12,000；流程圖 1–40 節點、0–80 連線。
  統計圖 1–5 數列、1–24 列資料，圓餅圖限一個非負數列且總和大於零；完整 JSON 及投影各最多 60,000。
- 心智圖 1–80 個已入圖節點、全圖 0–24 個待選分支，名稱 240、說明 2,000；完整 JSON 與投影各最多 60,000。
- 向量圖形 1–100 個物件，畫布寬高各為 1–4096 的整數，數值最多三位小數，不自動四捨五入。
  標題 600、物件名稱 120、文字內容 4,000；多邊形 3–80、折線 2–80 個頂點。完整 JSON 與緊湊投影各最多 60,000。
  伺服器最終序列化仍檢查容量，非預設 PHP 精度設定可能更早達到上限；超限整筆拒絕，不截短。
- 網頁 1–20 區塊，cards／faq 各 1–12 條目；完整正規 JSON 與文字投影各最多 60,000。
  網頁／區塊／條目標題 600，眉標／按鈕文字 240，區塊內文 12,000，條目內文 6,000；超限不截短。
- 本版目標與修改意見最多 12,000；HTTP 請求最多 1 MiB；專案序列化資料最多 2,000,000。
- 每項目最多 60 個版本（含封存）及 60 次比較，超限不截斷原文。
- 6,000–24,000 output tokens 是模型請求預算，不保證可用性、生成字數或格式成功。

心智圖實際操作
1. 提供主題，AI 整理可探索方向後，明確按確認才生成根節點與待選分支。
2. 待選分支預設不入圖。勾選喜歡的分支並加入草稿，自填分支也可；最後明確另存大版或小版。
3. 點選節點可改名稱與說明、移動或明確合併。欄位須先套用或放棄，才可另存，舊版本完全不改。
4. 對談中的節點選單使用已保存來源，AI 只更新該節點的待選子分支，不自動改動已入圖節點。
5. SVG 匯出只畫已加入的節點；完整 JSON 與 TXT 也保留待選建議。固定腳本示範不是 AI，不能理解任意輸入。
