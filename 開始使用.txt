AI共創工作室｜第五階段：受限互動視覺與 p5.js 匯出

同一專案可建立多個創作項目，保留各自對談、目標、完整主／小版本、候選、正式版、固定引用、比較與定稿紀錄。
十二類已提供有界功能：標題名稱、短文、長篇文章、圖文、表格、圖表、心智圖、向量圖形、圖片創作、海報設計、網頁、互動視覺程式。
圖片創作只支援外部圖片上傳、保存及實際圖片分析，不提供 AI 像素生成／修改／融合。
圖文與海報是文字搭配已明確引用的固定圖片版本之原生排版；模型只收到圖片中繼資料，沒有圖片像素。
互動視覺程式提供受限幾何、可選動畫／游標互動、安全 Canvas 預覽與 p5.js 主程式匯出，不執行任意模型程式。「共聊」不在本次開發範圍。
沒有帳號／團隊權限。只能在 PHP 主機同一台電腦使用，不可公開部署、開放區網、代理或隧道。
原始碼：https://github.com/shinjia/ai-cocreation
公開原始碼不代表已公開部署；下載內容請依實際 commit 核對。

第一次安裝，不需命令列：
1. 完整資料夾放入 XAMPP 的 htdocs，名稱使用 ai-cocreation-series-php74。
2. 啟動 Apache，同機瀏覽器開啟 http://localhost/ai-cocreation-series-php74/public/
3. 依 HTTP 安裝頁完成檢查。私有資料夾可使用 C:/private/ai-cocreation-series-data，
   不得位於 htdocs、專案或公開 Alias。安裝不需要金鑰，也不呼叫 AI。
4. PHP 需 JSON、PDO SQLite、cURL、Session、zlib 等擴充。圖片上傳要求 upload_max_filesize 至少4M、post_max_size 至少5M；記憶體不足時縮小圖片，不關閉安全限制。
5. 在 AI 系統設定管理成員稱呼、OpenAI／Ollama、模型與啟用狀態，閱讀資料傳送及費用說明後勾選。
   OpenAI 既有 Key 只貼在專用密碼欄，Web root 外工作階段暫存最多30分鐘；請勿貼入對話。
   Ollama 須已在 PHP 主機同機啟動，預設 http://127.0.0.1:11434。
6. 建立專案時一次選好模型；未綁定的空專案可稍後明確綁定。中央設定變更不會偷偷換模型。
   模型清單只在按鈕操作後查詢，不自動下載或推論；清單可見不代表支援圖片或所需輸出格式。

基本流程：
建立專案 → 新增／選取創作項目 → 對談 → 閱讀主軸與方向 → 明確按確認才生成候選
→ 選一版持續微調，或獨立比較／明確融合 → 自行採用正式版 → 項目定稿 → 專案結案。
正式版完整內容置頂，下方為01對談、02主軸與方向、03候選。方向足夠不會自動生成。
AI 修改保存完整小版本，手動可另存主版或小版；原版與正式版不被覆寫。比較依各版自己的目標，不強選勝者。
長文需明確勾選 AI 修改的段落，保留未選原文；短文完整修改。只有標題名稱採用正式版時同步改創作項目名稱，專案名稱不變。
封存／還原、重新開啟討論均保留歷史；固定圖片引用不會跟著來源後續改版自動更新。

圖片、圖文與海報：
1. 圖片項目選擇外部 PNG／JPEG，在瀏覽器縮小、旋轉並準備 PNG；明確按上傳才保存，無 AI 呼叫。
2. 私有 PNG 僅經已驗證的項目／版本讀取，不產生公開圖片網址。PNG最多4MiB、最長邊2048像素。
3. 圖片分析另有一次明確同意，綁定專案固定模型；之後明確送出或比較才傳送實際像素，可能收費。
4. 圖文／海報若要使用圖片，先明確引用同專案已保存的圖片版本，再由原生區塊安排。也可純文字排版，沒有假圖。
5. 海報02分別確認視覺風格、完整文字、圖文排列。編輯器先套用或放棄欄位草稿，再另存完整版本。
6. 只有正式作品自動載入圖片；候選等預覽需明確按載入。圖文／海報AI不分析圖片像素，也不生成新圖片。
7. 已保存排版可下載含固定PNG副本的單檔HTML，內嵌圖片累計最多20MiB；缺圖、超限或來源變更會拒絕，不輸出缺圖檔案。
   HTML只有固定樣式、文字與圖片，無程式、外部連線或表單；JSON／TXT不包含圖片像素。
8. 私有資料備份才包含完整圖片歷史。專案JSON、單版HTML或PNG都不取代完整備份。

其他原生作品：
表格有列欄格，可匯出CSV／TSV，不執行公式。圖表提供受限流程圖文字／SVG與選用統計模式，來源可手動複製到其他工具，不自動連動。
心智圖的AI分支先進待選區，勾選才加入草稿；可自填、移動、合併及復原，最後明確另存。
向量圖形以原生幾何／文字物件編輯並匯出SVG；未驗證外部工具「形坊」匯入相容性。
網頁先確認風格、內容結構與操作功能，支援原生單頁導覽及問答，匯出HTML；沒有公開部署、任意程式或外部表單。

互動視覺程式：
1. 02依序確認畫面視覺、動畫效果、參數設定、互動表現。畫面必要，動畫／互動可明確不使用。
2. AI只產生受限視覺資料，不是任意JavaScript；支援矩形、橢圓、線段及指定動畫／游標模式。
   最多40圖層、24參數，畫布最長2048，單次播放最多60秒。初始只顯示靜態影格，播放及游標互動皆須明確啟用。
3. AI參數建議先不勾選，使用者選用後才可調整。保留目前值、前次值；隨機只影響已選參數，草稿可復原。
4. 先套用或放棄欄位，再另存完整版本。來源切換、候選修改與採用均不覆寫舊版或自動定稿。
5. 可匯出p5.js主程式、JSON、TXT。主程式需自行提供p5函式庫，不附HTML、不自動載入CDN。
   本機預覽用原生Canvas，不是p5 runtime；匯出以相同受限繪圖規則產生程式。沒有任意程式匯入／執行。
6. 各版參數選用／值有衝突時仍可比較；融合前需先手動統一，不會自行選一版控制設定。

既有同系列安裝：安全覆蓋升級，不要重新安裝
1. 停止所有寫入，離線備份原程式、config.local.php及整個私有資料夾，包含SQLite與可能存在的journal／WAL。
   備份可能含Session與仍有效的暫存Key，須私密保管，不上傳或分享。不要求清除或重新輸入仍有效Key。
2. 合併覆蓋新版原始碼，不先刪舊資料夾，不覆蓋config.local.php或私有資料，不重設資料庫。
3. 保留原網址、瀏覽器Cookie／Session。快取標籤20261021-version15，必要時強制重新整理，不清除Cookie。
4. 保留所有舊ID、版本、來源與定稿。舊規劃項目啟用新能力，不補造不存在的歷史內容。
5. Key原有30分鐘期限不變。自然到期後才依本機頁面要求重新輸入，更新不延長期限。
